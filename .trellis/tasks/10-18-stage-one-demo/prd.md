# Stage-one demo-ready public browsing

## Goal
Deliver a usable, isolated demonstration of the stage-one public mini program without waiting for production brand facts, customer consent or storage procurement. User explicitly approved fictional demonstration data and autonomous implementation.

## Acceptance
- Six business categories, six demo packages, six visibly synthetic work examples; no fake callable phone numbers or implied customer consent.
- Public query and controlled media interfaces; configurable external catalog and media root; content-derived version and fail-closed malformed updates.
- Demo vs production guardrails; media metadata and byte requests recheck owner eligibility, use no-store, reject original/Range bypass and unsafe filenames.
- Client resolves gateway media, labels demo data, offers real share routes and copy contact UI, and hides old media on background/resume with stale-response protection.
- Contract/adapter tests, frontend tests and WeChat build pass. Document exact runtime setup and outstanding production/device limitations.
- Do not add appointments, orders, payments, private delivery, anonymous writes or a new admin product.

## Non-goals
Production authorization source, linearizable revocation across external systems, real customer photos, official AppID/domain procurement, WeChat device certification.
