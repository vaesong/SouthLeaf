# 小程序温润轻奢UI细化与体验打磨 (v4 Refinement)

## Goal

在已落地温润轻奢（v4）基调的基础上，全面落地方案 A 悬浮毛玻璃胶囊底栏、首页大片故事前置、作品双列自适应瀑布流、人民币货币符号、微信分享高清封面、关于二维码交互及各页面细节体验打磨。

## Requirements

1. **底栏体系**：采用方案 A「悬浮毛玻璃灵动水滴胶囊」底栏（`custom-tab-bar`），通透圆润毛玻璃材质、焦糖色指示短线，全 Tab 页统一联动，消除传统贴底硬边底栏割裂感；页面留足底部安全距离。
2. **首页排版**：将「近期摄影故事（大片杂志流：全宽封面大画刊 + 齐平双联对视）」提升至「精选拍摄方案」前面，符合以客照打动人心为主的理念。
3. **排序指示**：修复作品页「最新/最早」下拉排序的下三角指示符号，采用精确居中对齐的几何微箭头，杜绝视觉歪斜。
4. **作品画册流**：作品列表移除冗余的单列「列表」模式，保留「自适应瀑布流（默认）」与「等高画册」双模式。瀑布流采用左右双列独立均衡布局，确保 1~2 张或少图时左右均匀分布、不卡边。
5. **二维码预览**：关于我们页面对演示占位二维码提供友好的交互反馈（弹窗提示演示占位码，正式营业后开放扫码），并严格保全安全契约不触发无效扫码。
6. **我的页面异常反馈**：预约服务不可用时，以温情卡片说明“暂未开放预约”，彻底移除无意义的“重试”按钮。
7. **实体字符修复**：修复首页签名中的 HTML 实体残留，展示为标准的「—— 安娜 & 方女士」。
8. **价格符号规整**：所有套餐与服务价格展示统一规范加上人民币符号（`¥`），包含起步价（如 `¥999 起`）和固定价。
9. **微信分享卡片精细化**：在全页面 `onShareAppMessage` 中显式指定高清封面 `imageUrl`（作品封面、套餐大图、首屏大作），杜绝随机制品截图。

## Acceptance Criteria

- [ ] `app.json` 启用 `custom: true`，`custom-tab-bar` 正常渲染并在 5 个 Tab 间无缝同步选中态，底栏具有毛玻璃悬浮水滴质感。
- [ ] 首页大作故事置于套餐方案上方。
- [ ] 作品列表切换仅在瀑布流与等高画册之间循环，瀑布流左右两列自适应平衡。
- [ ] 首页主理人签名正确显示为「—— 安娜 & 方女士」。
- [ ] 价格标签均带有「¥」符号。
- [ ] 分享卡片带有清晰的封面大图 URL。
- [ ] `npm run verify` 全部 PASS（格式、79+ 单元与契约测试、技术文档校验 100% 通过）。
