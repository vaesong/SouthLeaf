# S1-C1 credential foundation

用户要求继续并委托普通技术决策直接落实。实现 D-201/ADR-004 的独立凭据核心增量：纯 Java lookup/verifier/事件端口、统一失败登录编排、受维护 Argon2id adapter 和资源边界。保留已有会话签发的事务版本重检，不让调用方提供 verifiedVersion。

验收：无默认账号/密码；原值 Unicode、长度/字节上界、无 trim/归一化；未知/禁用/格式错误账号走 dummy；错误密码/版本竞争统一拒绝；依赖/事件错误不变成凭据错误或成功；副本清理、结果脱敏；存储 hash 参数严格有界、并发最多 2、无队列；独立参考向量、实际负载基准、依赖扫描、原回归与产物隔离。

本任务只关闭 C1 门禁，不冒称整个 S1-C 完成。C2 的 V3/JDBC认证事件/runtime接线与 C3 账号 CLI/恢复/拒绝表仍须各自 G1 和真实事务/权限验证。此批不改 SQL/grants、不创建账号、不启 HTTP、不改公开服务/配置、不清旧 target、不提交推送。
