# 补齐轮播、档期、预约规则配置（子任务 B，待设计）

> 状态：仅记录需求。等 `11-01-admin-studio-ui` 验收后，再写 design.md / implement.md 并启动。

## 现状（已核对代码）

- 首页轮播 `heroItems` 由 `backend/public-api/.../PublicQueryService.readHome()` 从精选作品前 3 个生成；副标题（`公开作品` / `DEMO / 展示样例`）与按钮文字 `浏览作品` 写死，跳转固定为作品。
- 后台档期只有 `GET /api/admin/v1/bookings/slots`，没有开放、关闭档期的接口。
- 预约运营参数（Q04：提前多久可约、待确认多久过期等，带版本号）没有后台接口。

## 需求

1. 首页轮播单独配置：每张包含图片、主标题、副标题（选填）、按钮文字、跳转目标（作品 / 套餐 / 业务 / 关于我们）及目标 ID、显示开关、顺序；最多 5 张。随目录草稿一起保存、预览、发布、撤回。未配置时保留现有回退逻辑。小程序首页按配置渲染并能跳转到对应页面。
2. 档期管理：后台可开放新档期、关闭未被占用的档期；已有预约占用的档期不能直接删除。
3. 预约规则：后台可查看与修改运营参数，每次修改生成新版本；未配置时维持“拒绝预约”的现有规则（Q04）。

## 约束

- 数据库变更走现有迁移体系；不触碰 3306 上的原有服务与真实数据。
- 遵守 `.trellis/spec/backend/*` 与跨层思考指南；公开接口字段变更需同步 `frontend/api/public.js` 与测试。
