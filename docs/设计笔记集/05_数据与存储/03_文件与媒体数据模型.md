# 阶段一文件与媒体数据模型

> 文档编号：D-503。状态：阶段一已实施的公开衍生图模型；私密原图、上传工作台、网盘交付属于其他阶段，不在此伪称完成。

## 1. 事实与字节分离

- media_asset：发布内稳定引用 id 与 alt_text；不能把文件路径当公开 id。
- media_variant：主键 (release_id,media_id,variant)，仅 thumbnail/preview；私有 object_key、SHA-256、长度、尺寸、content_type。
- CHECK：1–4 MiB、宽高 1–8192、PNG/JPEG。缺任一必需变体使该发布装载失败，不能临时绘制或回退原图。
- 作品封面和相册、业务/套餐封面、成员肖像、平台二维码均通过同发布外键和归属关系引用媒体；作品内容还须评估当前准确授权。

## 2. 存储和公开边界

当前适配器 FileMediaObjectStore 的根目录由环境注入，位于私有目录，不挂静态 HTTP。数据库中的对象键不是公开下载 URL；DTO 只给出网关受控路径。内容寻址对象不能覆盖：更新内容创建新对象和新发布。

每次 GET/HEAD：验证 id/variant → 获取当前发布及绑定资格 → 读取限定大小字节并核对真实路径/根目录、长度、SHA-256 → 再查发布/授权资格戳 → 一致才返回。无远程来源 URL、无原图变体、无静态旁路；no-store/nosniff；Range 拒绝，不以 304 绕过复查。

## 3. 演示与真实素材

显式演示导入阶段生成图像、完整解码确认尺寸后存储。70 个变体引用允许指向相同内容寻址对象；本次恢复演练实测 42 个唯一文件，不应把行数当文件数。

旧 frontend/static 中 61 个未核验素材已移到本机非公开 archive/legacy-frontend-assets，8 个新 tab SVG 源移到 frontend/design/tab-icons，逐文件 SHA-256 保持。归档不属于运行数据、不允许构建导入，也不自动提交。当前 static 仅 8 个批准的 tab PNG；构建遇到任何额外静态素材直接失败，不再先复制旧图再删掉。

真实照片仍须完成权属、客户公开授权、衍生图加工、敏感元数据清理及审核记录。本地旧图片和 DEMO_GENERATED 字段都不能替代这些证据。

## 4. 回收、备份与撤回

数据库快照与其引用的不可变对象一同备份；对象清理须先证明所有仍保留发布、授权与备份不再引用，不能按当前首页未展示就删。撤回更新当前事实及修订；终止公开资格不等于已完成隐私物理删除。最终复核后在途发送窗口及客户端持续显示治理尚须正式协议验收。

恢复演练、保留与版本规则见 [D-504](04_数据迁移、备份与保留.md)。当前没有垃圾回收后台、客户删除审批或对象存储供应商接入；不添加空适配器来假装提供这些能力。
