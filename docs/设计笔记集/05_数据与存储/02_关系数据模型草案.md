# 阶段一关系数据模型

> 文档编号：D-502。状态：阶段一已实施；阶段二/三模型未在此承诺。当前唯一 schema 定义是 [V1 SQL](../../../backend/public-api/src/main/resources/db/migration/V1__public_catalog.sql)，已应用后不得改写；后续使用 V2+。

## 1. 模型归属

这是公开发布读模型，不是客户、订单或私密交付主库。原 southleafdb 不迁移、不回读。演示库 southleaf_public、独立测试库 southleaf_public_it，均为 MySQL 8.4/InnoDB/utf8mb4_bin。

| 关系 | 职责与关键约束 |
|---|---|
| catalog_release | 发布身份；content_version 唯一；模式 demo/production，生产必须 APPROVED |
| active_publication | singleton_id=1 的唯一当前指针，外键指向发布 |
| studio_brand / studio_contact | 每发布一组品牌与联系资料；品牌英文等从库返回 |
| team_member / team_specialty | 发布内成员及有序明细；公开页面仅呈现批准的成员资料，不显示专长标签 |
| contact_channel | 微信/抖音/小红书账号、二维码及状态；发布内顺序唯一 |
| photography_business | 发布内业务；顺序唯一；封面外键引用同一发布媒体 |
| catalog_package / package_line | 套餐当前展示事实及 SERVICE/TIP/NOTICE 有序明细，不产生订单价格快照 |
| public_work | 作品候选、公开状态、候选/绑定版本、主体范围；索引覆盖发布/状态/时间/id |
| work_business / work_media | 同一发布内作品业务与媒体集合；有序且去重；外键不跨发布 |
| home_featured_business / home_featured_package | 显式精选关系；position 0–2。当前首页不展示套餐副区，不自动推导精选 |
| media_asset / media_variant | 媒体语义与私有预制变体；变体维度/长度/类型 CHECK 约束，详见 D-503 |
| public_authorization / authorization_media | 每作品当前授权事实及准确媒体范围；与发布、候选、绑定、主体、用途、渠道和期限一起评估 |

共 19 张业务表；Flyway 自有历史表另计。准确列类型、可空性、唯一键、外键和 CHECK 以迁移 SQL 为准，不在本文复制第二份 DDL。

## 2. 一致性与发布

1. 为完整新内容创建新的 release_id/content_version，写入所有关系和已核验媒体。已发布内容不可原地改写，否则会破坏不可变缓存协议。
2. 审核当前授权事实。**授权必须属于目标 release_id**；仅复用 workId/候选版本/绑定版本不足以授权另一次发布。事实有效且主体/媒体等范围精确一致才可展示。
3. 在受控事务内更新授权与其媒体关系，最后切换 active_publication；记录维护人、审批人、变更原因和外部证据引用。没有匿名发布或修复 API。
4. 授权表单作品主键只保存当前事实，不冒充完整授权审计系统；真实证据、历史留痕和责任确认是外部运营门禁。
5. 每请求确认当前指针；data/meta 来自同一发布。授权另以当前 repeatable-read 批次读取，两条 SQL，不按作品 N+1。
6. 缺失/未知/撤回/范围不符拒绝公开；依赖故障为不可用，不是成功空目录。旧游标跨发布为 409。

更新授权父子关系时须尊重外键：在同一事务内移除待替换的 authorization_media 子行、更新父事实并写入目标发布子行，再切指针；不得关闭外键来发布真实内容。

## 3. 权限和容量

运行身份仅 SELECT；迁移与测试身份分开。公开发布上限 1,000 作品、1,000 套餐、100 业务，超限显式失败。这里只是阶段一有界读模型，不是负载性能验收结论。物理索引优化必须有查询/负载证据，并通过新迁移实施。

## 4. 验证与边界

真实 MySQL 集成覆盖持久化、外键、权限、TLS、发布/游标、当前授权和跨发布事实误复用。演示事实标记 DEMO_GENERATED；字段值不能证明真正客户同意。真实资料、生产发布审批与并发运维验收仍是阻塞，不能因为本模型可用就勾选通过。
