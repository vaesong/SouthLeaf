# 对象存储与网盘契约

> 文档编号：D-405
> 文档状态：评审中（阶段一可编码草案）
> 适用范围：阶段一公开媒体只读；网盘/私密交付留至阶段三
> 更新日期：2026-10-08
> 上游需求：A05、A06、A15、A16
> 上游架构：AT08、AT09
> 关联计划：P01；对齐 D-401、D-501、D-601、D-602、D-702、D-203～D-207

## 1. 设计目标

沿用 Java 21 / Spring Boot / MySQL，通过私有存储适配层和可撤回媒体网关支持匿名只读展示，不要求 Redis 或消息队列。
不交付管理后台、上传工作台、登录、预约、订单、支付或私密交付；本文供应商方法/字段为候选，尚未选定真实供应商。
A15 `delivery` 持有授权事实，A06 `works` 计算资格，A05 `content` 编排；供应商“可下载”不等于业务“可公开”。

## 2. 对象存储能力边界

阶段一必需候选能力：非公开对象、受限服务端读取、稳定对象版本/等价不可变引用、元数据和有界流读取。
原图、展示衍生图、证据与私密交付文件分用途隔离；查询凭证只读展示区域，不能读取/列举原图与证据。
原图始终非公开且无阶段一原图下载；展示衍生图也不使用公共桶或可绕过当前资格的 CDN 直链。
供应商的上传、删除、列举、签名和回调能力不自动进入阶段一；能力不足需重新评审读取方案，不能降低授权检查。
`PrivateObjectReader.head(objectRef) → ObjectMetadata / StorageFailure`；`open(objectRef, objectVersion) → BoundedStream / StorageFailure`。
`ObjectMetadata` 候选仅内部使用：`version/contentType/contentLength/checksumKind/checksum/width/height`，未知字段不填造值。
适配器固定受控服务端端点；客户端不传入桶、key、域名、远程 URL 或供应商请求头，避免任意对象读取/远程抓取。

## 3. 上传、回调、校验和元数据

阶段一首批素材通过待确认受控导入流程校验登记，不开放上传 API、预签名直传、上传工作台或供应商回调路由。
登记输入为所属模块/资源/用途、内部对象引用、不可变版本与真实校验摘要；输出内部 asset 引用、状态和绑定版本。
未通过真实类型、大小、解码/尺寸和完整性检查的对象不能建立公开绑定；不信任扩展名、客户端 MIME 或“上传完成”。
ETag 未经供应商契约证明不当 checksum；不得伪造 MD5/尺寸或在版本不明时盲读最新对象。
展示衍生图须移除 EXIF/GPS 等非公开信息，允许类型、压缩/尺寸、水印及检查规则在真实素材验证后确认。
未来上传回调若接入，另评审签名、去重、主动查证和结果未知处理；回调成功不产生公开授权或发布事实。

## 4. 私有对象、短期访问和下载

`PublicMediaReader.resolve(ownerPublicId, mediaId, purpose) → PublicMediaDTO / 安全失败`，只消费已登记的资源媒体绑定。
公开字段沿用 D-401：`id/thumbnailUrl/previewUrl/width/height/altText/sortOrder`；不返回 key、对象版本、供应商地址或签名参数。
候选 `GET/HEAD /api/v1/public/media/{mediaId}/{variant}` 仅 `thumbnail/preview`，返回有界媒体流；不开放 `original` 或正式下载。
用例输入 `mediaId/variant/publicVersion?` 只是定位条件，输出当前合格衍生图/安全 404/503，不以 ID/版本充当许可。
每次读取经所属模块端口核验主库当前发布/绑定及 A06 资格（A06 读取 A15），不用延迟副本或旧事务快照；渠道/用途/有效期须匹配，显式旧绑定版本不匹配返回安全 404。
授权读取超时、未知、证据/主体未核验、撤回或过期 fail-closed；品牌/套餐人物媒体不因所属页面不同豁免权利检查。
私有对象由网关服务端流式输出，禁止 302 到供应商、外发短签名或原图/网盘兜底；URL 短期有效不能替代可撤回读取。
作品媒体 `Cache-Control: no-store`、边缘不缓存，`HEAD` 仍校验，不支持绕过检查的 304/Range；元数据缓存不替代资格。
客户端首页/列表/详情/预览/新分享未二次确认不得显示旧作品媒体；离线/刷新失败/后台恢复待核验只显示安全占位。
撤回提交后新的读取拒绝，投影/缓存/任务失败不能恢复旧入口；在途流中止及目标时限待实测，不承诺删除已发出的副本。

## 5. 网盘人工补交和链接撤销

网盘补交仅为 P01 阶段三边界，阶段一不建分享链接、接收人登记、家庭授权、下载入口或网盘供应商适配实现。
未来须记录接收人、文件范围、有效期、操作人和原因，结合 A15 私密授权；不能把网盘分享当作匿名公开作品媒体。
未来候选 `CreateSupplementLink(scope, expiresAt, recipientRef) → linkRef / UNKNOWN`、`RevokeLink(linkRef) → VERIFIED/UNKNOWN`。
供应商能力、真实链接撤销和人工核验方式待确认；不知道撤销结果就不能声称已撤销，未确认能力不伪造供应商字段。

## 6. 外部状态映射、超时和重试

| 内部结果/外部故障分类 | 公开读取结果 | 处理规则 |
|---|---|---|
| 绑定不存在/撤回/资格 UNKNOWN | `PUBLIC_RESOURCE_UNAVAILABLE`/404 | 统一不可用，不透露授权内部原因 |
| 参数/变体非法 | `PUBLIC_QUERY_INVALID`/400 | 不回显原值，无任意 key/URL 读取 |
| 已合格媒体对象缺失/拒绝/校验失败 | `PUBLIC_MEDIA_UNAVAILABLE`/503 | 单项失败，内部区分分类，不回退原图 |
| 已合格媒体超时/限额/网络未知 | `PUBLIC_MEDIA_UNAVAILABLE`/503 | 有界重试，未知不当成功，不复用旧地址 |
| 授权/必需查询依赖整体故障 | `PUBLIC_SERVICE_UNAVAILABLE`/503 | 无法安全完成查询，不伪装成功空结果 |
| 响应转换失败 | `PUBLIC_RESPONSE_INVALID`/500 | 通用提示，不透传异常/供应商报文 |

控制连接/读取超时、并发流、最大字节和读重试总预算；只重试可安全重复的 `head/open`，流已输出不得重新拼接整图。
图片流成功不套 JSON；发送前失败可用 D-401 错误外层，发送中断只终止并记脱敏 requestId/streamOutcome。
JSON 部分媒体可独立失败时外层仍 `OK`/200，失败媒体用网关错误处理；必需封面/区块降级不能违反 DTO 非空约束。

## 7. 孤立对象和业务登记不一致

`CheckMediaBinding(mediaRef, expectedVersion) → VERIFIED/MISSING/MISMATCH/UNKNOWN`，D-206 任务核对登记与对象元数据。
对象存在但无登记、登记缺对象、版本/摘要不符均不自动公开，记受限待办；未知结果拒绝相关媒体并有限重试。
替换采用新版本并重新核验绑定，失效旧引用；孤立对象不自动补登记/删原图，清理由独立确认的保留规则决定。
恢复不能把备份资格、旧 URL 或任务成功当许可；重读当前授权/发布，旧任务按版本比对不得复活撤回作品。

## 8. 凭证、密钥和安全边界

凭证依 D-207 从部署受限来源解析，开发/测试/生产隔离；后端最小只读权限不进入小程序包、公开响应或文档。
签名、连接串、桶/key、私密地址、网盘链接和授权证据不进日志；仅记录资源引用、requestId、归一失败类型和时长。
公开端不提供存储目录枚举、临时凭证、内部健康明细或供应商错误原文；安全观测不创建匿名访客身份/画像。
缓存失效或告警故障不回滚撤回，维护/删除/上传权限独立；公开媒体访问不等于获得私密原图或证据访问权。

## 9. 测试和验收

- `S1-WORK-02/03`、`S1-CACHE-02/03/05`：资格超时/未知、撤回与读取并发、旧 URL/缓存/304 和任务失败均不能展示旧作品媒体。
- `S1-API-06/07/08`：桶匿名读取、原图/私密路径、签名/供应商字段泄露、伪造变体/URL 均被阻断且可脱敏追踪。
- `S1-WORK-05`：存储缺失/拒绝/限额/超时、错 MIME/摘要/版本和半流中断产生安全单项失败，不泄密、不回退原图。
- `S1-CACHE-04`：孤立对象核查、替换/恢复和乱序任务不重复事实、不恢复旧许可；真机验证图片/预览缓存与重新进入行为。

## 10. 供应商待确认问题

设计假设：候选供应商支持非公开服务端读取和不可变版本；未确认前不写供应商名称、桶地址、容量、TTL 或 SLA。
D-602 的先展示首页/列表缓存与本稿二次确认冲突；D-401 的自然过期和媒体 200/503 映射需主代理统一到网关语义。
首批真实素材、人物/监护授权、品牌/套餐权利依据、导入核验与发布撤回责任上线前确认，缺项不伪造/不公开。
真实供应商版本/checksum/权限/限额/错误映射、域名与小程序平台行为、流中止/撤回目标、保留/恢复需联合实测确认。
阶段三网盘链接创建/撤销、接收范围和人工核验独立评审；完成本文草案不能当作真实供应商联调或上线验收已通过。
