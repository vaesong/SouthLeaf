## 9. 内部架构

```text
Controller/Adapter
  → Application Service
  → Domain Rule/Domain Service
  → Repository/Port
  → Infrastructure Adapter
```

说明：

- 应用服务负责用例编排和事务边界；
- 领域规则负责不变量和状态转换；
- Repository/Port 负责抽象存储和外部能力；
- 适配器负责供应商协议、重试和原始状态转换；
- 模块不得直接读其他模块的表或调用供应商 SDK。
