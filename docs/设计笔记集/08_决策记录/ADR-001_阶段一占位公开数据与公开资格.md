# ADR-001 阶段一占位公开数据与公开资格的最小实现

> 决策状态：已被用户确认的独立新库、无兼容架构取代。本文仅保留历史决策，不允许据此恢复 JSON 运行链路；现行规范见 AT10、D-502/503/504。

> 文档状态：临时决策（待设计评审确认）
> 日期：2026-10-18
> 关联：D-101 内容与品牌、D-102 作品与案例、D-308 成片交付与授权（第 7、8 章仍为骨架）、P01 阶段一

## 背景

阶段一需要后端公开读取接口可以联调，但正式内容的来源、维护流程和 A15 授权事实的存放位置尚未确定。
设计清单要求：未确认的资料不得发布，授权未核验或无法确认时作品不得公开，不能把占位数据当作生产事实。

## 决策

1. **数据源临时使用受控 JSON**：`backend/src/main/resources/public-data/catalog.json`，带 `schemaVersion`，启动时校验。
   JSON 只是开发和联调的载体，后续替换为已确认的数据源时，读取器保持端口不变。
2. **品牌与联系方式需要确认后才发布**：`brand.confirmed` 与 `contact.confirmed` 为 `true` 才返回，否则接口返回"内容当前不可用"或空。
3. **作品必须同时满足以下条件才公开（fail-closed）**：
   - `publicationStatus = published`；
   - 有封面媒体引用 `coverMediaId`；
   - 授权事实 `result = VALID`，`channel = WECHAT_MINI_PROGRAM`，且存在未过期的 `validUntil`；
   - 列表过滤，详情统一返回不可用。
   任一条件缺失或无法确认，均视为不公开。
4. **授权事实字段是 A15 的占位**：`authorization` 字段在 JSON 中只表示"授权结果"，不是授权证据正文。真实事实必须来自已批准的 A15 来源。
5. **媒体读取暂未接通**：`coverMediaId` 只是引用，媒体网关未完成前，作品和套餐的图片字段均为 `null`。

## 当前结果

- `brand`、`contact`：占位数据未确认，不对外返回。
- `works`：JSON 中为空数组，因此公开作品列表为空。这是按规则应有的结果，不是故障。
- `businesses`、`packages`：占位内容已发布，可以返回。

## 后果

- 首页在品牌确认前没有品牌信息，在授权作品接入前没有作品轮播。
- 上述空态会被前端显示为"内容暂不可用"或空列表，需要在小程序验收中确认体验。

## 待办（阻塞阶段一验收）

1. 补全 D-308 第 7、8 章：公开案例授权的资格输入、撤回联动和 A15 事实契约。
2. 确定 A15 授权事实的真实来源和接口。
3. 媒体网关：封面和图片的受控读取，以及撤回后的即时阻断。
4. 工作室确认品牌与联系方式，并把 `confirmed` 置为 `true`。
5. 确定公开数据的维护方式与责任人（设计清单 2.2）。
