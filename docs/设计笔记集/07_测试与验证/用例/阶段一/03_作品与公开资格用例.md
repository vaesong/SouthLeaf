## 1. 覆盖摘要

| 场景组 | 主用例 | 主用例数 | 重点安全面 |
|---|---|---:|---|
| WORK | `S1-WORK-01`～`S1-WORK-06` | 6 | 合格公开、无授权/资格未知、授权撤回、作品下架、单媒体失败、固定 ID/对象注入 |
| 公开入口 | 每个适用用例 | 4 类 | 首页聚合、作品列表、作品详情、SouthLeaf 受控媒体网关 |
| 缓存与复核 | 每个媒体相关用例 | 持续断言 | 作品媒体 `Cache-Control: no-store`；每次展示前服务端复核当前发布、绑定、用途、变体、时间和授权/资格 |
| 合计 | D-702 对应场景全部落地 | 6 | 所有主用例与变体初始状态均为 `NOT_RUN` |

本文件只定义测试设计，不记录任何“通过”结论。公开作品安全以服务端当前事实为准：只有资源存在、公开版本已发布、未过期/未下架、A15 授权资格有效、媒体绑定与用途有效时才能生成公开结果。资格未知、读取超时、证据缺失、范围不匹配、撤回或失效均必须 **fail-closed**，不能由客户端、缓存、旧 URL、304、Range、本地文件或失效任务失败恢复公开。

D-401 已锁定阶段一公开错误码及 HTTP 映射。本文件涉及的核心映射为：公开可用 `OK/200`；不存在、未发布、下架、授权撤回、资格未知和资格失效统一 `PUBLIC_RESOURCE_UNAVAILABLE/404`；资格已确认但独立媒体网关本次读取失败为 `PUBLIC_MEDIA_UNAVAILABLE/503`；主资源仍可用的可选媒体部分失败保持 `OK/200`，通过成功响应内可选媒体缺失或评审后既有契约表达，不能同时解释为 200 和 503。错误响应和作品媒体响应均使用 `Cache-Control: no-store`。

接口路径、DTO 字段、媒体网关生产域名、变体参数和响应外层仍为草案。测试按“首页、列表、详情、媒体网关”资源语义建立观察点，执行时映射评审后的实际契约，不假定现有控制器、类名、API 路径、数据库表、存储供应商或签名格式。

测试图片必须是自有合成媒体，不使用真实客户照片、授权证据原件或生产签名地址。配方名表示待准备的可重复数据状态，不表示仓库中已存在同名 Fixture。

## 2. 公开资格与入口断言矩阵

| 资源状态 | 首页 | 列表 | 详情/旧链接 | 媒体网关 | 对匿名访问者的公开语义 |
|---|---|---|---|---|---|
| 已发布 + A15 授权有效 + 媒体绑定/用途有效 | 可返回符合编排的摘要 | 可返回 | 服务端重查后可返回 | 每次读取复核后可返回；响应 `no-store` | `OK/200`，仅公开白名单字段 |
| 无授权、待核验、资格未知/超时/无法证明 | 不返回 | 不返回 | 不可用 | 不返回媒体 | `PUBLIC_RESOURCE_UNAVAILABLE/404`，fail-closed |
| 授权撤回/失效/过期/范围不匹配 | 移除 | 移除 | 旧链接不可用 | 旧引用不可用 | `PUBLIC_RESOURCE_UNAVAILABLE/404`，不暴露内部原因 |
| 作品下架/未发布/不存在 | 不返回 | 不返回 | 不可用 | 不返回媒体 | `PUBLIC_RESOURCE_UNAVAILABLE/404`，不可枚举内部状态 |
| 资格有效、主资源可用、一个可选媒体读取失败 | 过滤失败可选媒体或按既有契约降级 | 同左 | 文字和其他已确认媒体可用 | 该次独立读取 `PUBLIC_MEDIA_UNAVAILABLE/503` | 聚合/详情仍 `OK/200`，不得泄露存储地址 |

该矩阵是所有 WORK 用例的共同断言。页面截图只能证明端侧表现，不能单独证明服务端过滤或媒体网关复核；每个安全用例需保留脱敏响应/响应头、`requestId` 和服务端资格检查的可观察证据。

## 3. 详细用例

### S1-WORK-01 合格作品公开

- **用例 ID**：`S1-WORK-01`
- **名称**：资格有效作品在首页、列表、详情和媒体网关按当前事实安全展示
- **优先级**：P0
- **类型/建议测试层**：公开资格正向决策与跨入口一致性；领域决策表 + 查询/媒体集成 + 接口契约 + 页面/真机
- **规则来源**：D-702 §3.3 `S1-WORK-01`；D-401 §2～§7、§9；D-602 §2、§7、§9；A15 §2.3、§10～§11、§14.5；D-701 §2～§5；P01 §3
- **前置条件**：
  1. 使用自有合成图片创建作品；作品公开版本已发布且未过期、未下架。
  2. A15 授权事实明确、有效，覆盖当前作品/图片、公开展示用途、目标渠道和当前时间；涉及的人物/监护范围无待核验项。
  3. 封面和详情媒体均正确绑定作品，媒体用途、变体和顺序有效；另放置一个未绑定媒体哨兵和一个私密媒体哨兵。
  4. 作品被加入首页精选编排，并可从作品列表、详情和受控媒体网关观察。
  5. 可观察服务端当前资格检查及媒体响应头；不依赖客户端提交的资格字段。
- **测试数据**：`合格公开作品三媒体有序集`、`有效A15范围匹配授权`、`未绑定媒体哨兵`、`私密媒体哨兵`
- **步骤**：
  1. 记录作品、授权范围、媒体绑定、用途和预期 `sortOrder` 基准，不记录真实授权原件。
  2. 冷启动首页，等待当前资格确认完成后记录精选作品摘要和封面。
  3. 进入作品列表，定位同一作品并记录标题、业务标签、封面和排序位置。
  4. 进入作品详情，记录文字、媒体数量、媒体顺序、替代文本和关联公开信息。
  5. 分别重新加载封面和详情媒体；每次记录媒体网关请求、资格检查结果及响应缓存头。
  6. 从后台恢复、下拉刷新、Tab 返回和分享/扫码入口重新进入作品，观察媒体从待确认到展示的过程。
  7. 检查公开响应、页面、本地缓存和媒体引用中是否出现授权内部标识、客户资料、证据、内部备注、原始存储 key、供应商直链、公共桶地址或永久签名参数。
- **预期结果**：
  1. 公开基准同时满足发布和授权资格，不因文件存在或历史展示推导资格。
  2. 首页只在当前服务端资格有效时返回作品；媒体资格确认前隐藏旧图，确认与网关读取成功后展示受控封面。
  3. 列表返回同一公开作品及正确业务标签，不包含未绑定/私密媒体。
  4. 详情重新执行服务端资格判断后返回；媒体按 `sortOrder` 一致展示，文字和关联信息来自当前公开版本。
  5. 每次媒体读取都重新检查所属作品、发布状态、绑定、用途、变体、当前时间和授权/资格；作品媒体响应含 `Cache-Control: no-store`，不以 304 或 Range 绕过检查。
  6. 后台恢复、刷新、Tab 返回和分享入口均先隐藏旧图再复核当前资格；旧 URL 或本地文件命中不作为资格证明。
  7. 公开面只含白名单公开字段和 SouthLeaf 受控媒体网关引用；不出现任何内部/私密哨兵或供应商信息。
- **证据要求**：首页、列表、详情和分享入口连续录屏；媒体顺序对照；每次媒体请求的脱敏响应头和资格检查事件；`requestId`；公开字段白名单检查；敏感哨兵未出现检查；后台恢复时“先隐藏、后确认展示”的逐帧或录屏证据。不得保存真实私人图片或完整签名参数。
- **阻塞/待决条件**：A15 资格结果的内部观测端口、受控媒体网关、最终 DTO/路径、媒体变体和真机入口未就绪时，相应集成/真机执行阻塞；媒体 `no-store` 和每次当前资格复核不是待决项。
- **初始执行状态**：`NOT_RUN`

### S1-WORK-02 无授权或待核验

- **用例 ID**：`S1-WORK-02`
- **名称**：无授权、待核验和资格未知作品在所有公开入口服务端 fail-closed
- **优先级**：P0
- **类型/建议测试层**：授权资格负向决策表与信息隐藏；领域单元 + 查询/媒体集成 + 接口安全 + 页面
- **规则来源**：D-702 §3.3 `S1-WORK-02`、§6；D-401 §4、§6、§7、§9；D-602 §4、§5、§7、§9；A15 §10、§12.3、§14.5；D-701 §1、§3
- **前置条件**：
  1. 作品内容本身存在并带唯一哨兵，但分别处于授权缺失、证据缺失/待核验、资格读取超时、资格结果未知、授权过期、用途/渠道/图片范围不匹配状态。
  2. 作品曾用媒体引用、路由标识或客户端对象可作为注入输入，但服务端当前资格均不可证明。
  3. 准备一个不存在作品标识，作为公开不可用响应对照。
  4. 可观察首页、列表、详情和媒体网关的服务端判断，而非只观察客户端过滤。
- **测试数据**：`作品无公开授权`、`作品授权证据待核验`、`作品资格读取超时`、`作品资格未知`、`作品授权已过期`、`作品授权范围不匹配`、`不存在作品公开标识`
- **步骤**（每个资格变体独立记录）：
  1. 启动当前变体，刷新首页并检查精选区块。
  2. 打开作品列表及按业务筛选结果，搜索作品哨兵。
  3. 使用作品公开标识或旧链接直接请求/进入详情。
  4. 使用此前保存的受控媒体网关引用请求封面和详情媒体，并尝试 304 条件请求、Range 请求及本地旧文件恢复。
  5. 对不存在作品重复详情和媒体请求，对比 HTTP、稳定码、公开文案和响应头。
  6. 检查响应、页面和客户端日志是否包含授权状态、超时依赖名、客户身份、证据、内部原因或原始存储信息。
- **预期结果**：
  1. 首页服务端聚合不返回当前作品；资格超时/未知不会回退为允许公开。
  2. 列表和筛选结果不返回当前作品，不能先返回全量再由客户端隐藏。
  3. 详情统一返回 `PUBLIC_RESOURCE_UNAVAILABLE`/404；页面显示“内容暂不可用”语义并可返回，不区分缺失、待核验、超时、过期或范围不匹配。
  4. 媒体网关按当前事实拒绝；304、Range、旧 URL、本地缓存和旧文件均不能绕过资格，错误响应为 `no-store`。
  5. 不存在与各资格不合格变体对匿名访问者具有相同稳定码、HTTP 映射和不可枚举语义。
  6. 对外结果不泄露授权证据、客户、内部资格状态、依赖名称、存储 key、供应商地址或堆栈；诊断只在脱敏服务端日志通过 `requestId` 关联。
- **证据要求**：每个资格变体的独立执行记录；首页/列表服务端结果；详情和媒体的脱敏请求/响应/响应头；不存在资源成对对照；304、Range、本地旧文件绕过尝试；资格检查日志摘要与 `requestId`；敏感哨兵未出现检查。
- **阻塞/待决条件**：资格依赖超时/未知的可控故障注入、媒体网关或服务端资格观测未就绪时，相应变体阻塞；不得用客户端隐藏代替服务端 fail-closed 证据。儿童、多人和监护核验细则未确认时，其状态必须保持不公开，而不是阻塞安全结果。
- **初始执行状态**：`NOT_RUN`

### S1-WORK-03 授权撤回

- **用例 ID**：`S1-WORK-03`
- **名称**：公开授权撤回后首页、列表、详情、缓存和媒体引用均停止后续展示
- **优先级**：P0
- **类型/建议测试层**：高风险状态转换、缓存失效与故障安全；领域/任务集成 + 接口安全 + 页面/真机
- **规则来源**：D-702 §3.3 `S1-WORK-03`、§6；D-401 §4、§6、§7、§9；D-602 §5、§7、§9；A15 §10.4、§11、§14.5；D-701 §4、§6、§7；P01 §3.3
- **前置条件**：
  1. 一个作品在撤回前满足 `S1-WORK-01`，已出现在首页、列表、详情并有可用媒体引用。
  2. 可通过受控授权流程撤回覆盖该作品/媒体/渠道的 A15 公开授权，并记录撤回事实生效点。
  3. 能分别控制或观察公开投影、首页编排、缓存失效/投影重建任务；准备“失效任务失败”变体。
  4. 设备 A 保留撤回前页面、旧链接和媒体引用；设备 B 为新会话或已清缓存设备。
- **测试数据**：`撤回前合格公开作品`、`覆盖整案的A15授权撤回`、`撤回前作品旧链接`、`撤回前媒体旧引用`、`缓存失效任务失败`
- **步骤**：
  1. 在设备 A 访问首页、列表和详情，记录撤回前基准、媒体引用和当前可见状态。
  2. 通过受控流程撤回公开授权，确认服务端当前授权事实已变为撤回；记录时间，不自行假定传播 SLA。
  3. 在设备 B 刷新首页和作品列表，并按原业务筛选。
  4. 在设备 A 使用撤回前旧链接重新进入详情；在已打开详情上执行刷新、Tab 返回和从后台恢复。
  5. 使用撤回前媒体引用重新请求；尝试 304、Range、本地缓存和旧 URL。
  6. 使缓存失效、投影重建或通知任务失败，再重复步骤 3～5。
  7. 比较不存在作品的公开响应，并检查匿名端是否看到客户姓名、撤回原因、授权范围或内部任务状态。
- **预期结果**：
  1. 撤回前基准仅用于证明状态发生变化，不形成永久公开资格。
  2. 授权撤回事实一旦生效，服务端当前资格立即按不可公开判断；传播时限未锁定不允许继续返回已知不合格作品。
  3. 首页和列表不再返回作品，相关公开筛选也不返回。
  4. 旧链接、刷新、Tab 返回和后台恢复均重新校验并返回 `PUBLIC_RESOURCE_UNAVAILABLE`/404；待确认期间隐藏旧图，页面清理对应本地媒体状态。
  5. 媒体网关拒绝旧引用；响应 `no-store`，304、Range、本地文件和旧 URL 不能恢复显示。
  6. 缓存/投影/通知任务失败只进入可观察补偿状态，查询与媒体网关仍依据当前撤回事实拒绝，绝不恢复公开。
  7. 公开结果与不存在作品具有统一不可用语义，不泄露客户身份、撤回原因、授权证据或内部任务失败详情；私密交付不在本阶段执行，且撤回公开授权不等于删除私密文件。
- **证据要求**：撤回前后四入口对照；受控撤回事实记录；设备 A/B 录屏；旧链接与媒体旧引用请求；`no-store`、304/Range 绕过检查；缓存失效任务失败时的服务端拒绝和脱敏任务状态；不存在资源对照；`requestId` 关联记录。证据不得包含授权原件或真实客户照片。
- **阻塞/待决条件**：受控授权撤回流程、资格结果接口、缓存/投影任务观测或故障注入未就绪时相应执行阻塞；具体缓存传播目标待评审，但 fail-closed、媒体 `no-store` 和当前资格复核不可因此阻塞或放宽。
- **初始执行状态**：`NOT_RUN`

### S1-WORK-04 作品下架

- **用例 ID**：`S1-WORK-04`
- **名称**：作品下架后所有公开入口统一不可用且不泄露内部下架原因
- **优先级**：P0
- **类型/建议测试层**：发布状态转换与枚举防护；领域/查询集成 + 接口安全 + 页面/真机
- **规则来源**：D-702 §3.3 `S1-WORK-04`；D-401 §4、§6～§9；D-602 §5、§7；A15 §11.3；D-701 §3、§7
- **前置条件**：
  1. 一个授权仍有效但当前已发布的合成作品出现在首页、列表、详情和媒体网关。
  2. 可通过受控内容流程将作品下架，并保存仅供服务端审计的测试原因哨兵。
  3. 准备不存在、未发布和授权撤回作品作为公开响应等价类对照。
- **测试数据**：`即将下架的合格作品`、`内部下架原因哨兵`、`不存在作品`、`未发布作品`、`授权撤回作品`
- **步骤**：
  1. 记录作品下架前在首页、列表、详情和媒体网关的基准。
  2. 通过受控流程执行下架，确认当前发布状态已生效。
  3. 刷新首页和作品列表，搜索作品标识、标题和封面哨兵。
  4. 使用旧链接直接访问详情，并在已打开页面执行后台恢复。
  5. 使用旧媒体引用发起普通、304 条件和 Range 请求。
  6. 分别访问不存在、未发布和授权撤回对照资源，比较公开响应。
  7. 检查错误体、响应头、页面和客户端日志中的内部下架原因哨兵。
- **预期结果**：
  1. 下架前基准可追踪，且媒体引用本身不是授权或发布凭证。
  2. 下架事实生效后服务端不再认定作品可公开，即使 A15 授权仍有效。
  3. 首页和列表服务端结果均移除该作品，不仅由客户端隐藏。
  4. 详情旧链接和后台恢复统一返回 `PUBLIC_RESOURCE_UNAVAILABLE`/404，页面给出安全不可用提示并清理旧图。
  5. 媒体网关按当前发布状态拒绝，错误响应 `no-store`；304、Range 和旧引用不能绕过。
  6. 不存在、未发布、下架、授权撤回在匿名公开端使用相同稳定码、HTTP 映射和不可枚举提示。
  7. 内部下架原因不出现在公开响应、响应头、媒体 URL、页面或客户端日志；服务端日志可通过 `requestId` 保留脱敏诊断。
- **证据要求**：受控下架记录；下架前后四入口响应/页面对照；旧链接和旧媒体请求；响应头；四种不可用状态的成对/成组比较；内部原因哨兵未出现检查；服务端当前状态判断与 `requestId`。
- **阻塞/待决条件**：公开内容受控下架流程或媒体网关未实现时动态执行阻塞；不得以直接修改假定数据库字段替代下架动作。传播 SLA 未锁定时不作时间门禁，但已知下架后的查询必须安全拒绝。
- **初始执行状态**：`NOT_RUN`

### S1-WORK-05 单张媒体失败

- **用例 ID**：`S1-WORK-05`
- **名称**：资格有效时单个可选媒体读取失败不阻断主资源且不泄露存储地址
- **优先级**：P1
- **类型/建议测试层**：媒体部分失败与恢复；媒体网关集成 + 接口契约 + 页面/真机
- **规则来源**：D-702 §3.3 `S1-WORK-05`；D-401 §3.3、§6、§7、§9；D-602 §2.3、§4、§9；D-701 §4、§6
- **前置条件**：
  1. 作品当前已发布且 A15 资格有效，详情至少包含三个按序媒体，其中一个为可选媒体。
  2. 可控地使该可选媒体在资格已确认后发生网关读取失败，其余媒体和主资源保持可用。
  3. 可在故障解除后重试单项媒体；准备供应商直链、原始 key 和永久签名哨兵用于泄漏检查。
  4. 必需封面失败的最终过滤/整体失败策略仍待评审，本用例只把“详情中的可选单媒体失败”作为确定前置。
- **测试数据**：`合格作品三媒体一项可选失败`、`媒体读取故障后恢复`、`存储地址敏感哨兵集`
- **步骤**：
  1. 打开作品详情，确认当前作品资格有效并记录三个媒体的预期顺序。
  2. 注入第二个可选媒体的单次网关读取失败，重新加载详情。
  3. 记录详情聚合响应、页面文字、第一/第三媒体、失败项占位和整体页面状态。
  4. 单独请求失败媒体，记录 HTTP、稳定码、响应头和公开错误体。
  5. 检查页面、聚合响应、错误响应和客户端日志中的供应商直链、原始 key、签名参数及内部异常哨兵。
  6. 解除故障，使用页面提供的单项重试路径；同时快速点击重试，观察是否产生请求风暴或顺序错乱。
  7. 在故障恢复前后重新检查当前资格，确保重试没有复用旧资格结果绕过现状。
- **预期结果**：
  1. 作品公开资格先由服务端确认；媒体读取失败不被误分类为授权未知。
  2. 主资源仍可用时，详情聚合保持 `OK/200`，通过可选媒体字段缺失或评审后既有契约表达失败项；不得把同一聚合结果同时返回 200 和 503。
  3. 文字、业务标签和其余已确认媒体继续可用；失败项有稳定占位/替代文本和可操作重试，不造成媒体顺序重排或整页崩溃。
  4. 独立媒体网关读取失败返回 `PUBLIC_MEDIA_UNAVAILABLE`/503，响应 `Cache-Control: no-store`；该码仅表示资格已确认后的单次读取失败。
  5. 所有公开面均不泄露原始存储地址、供应商、永久签名、内部堆栈或其他客户信息。
  6. 故障解除后单项重试可恢复该媒体；重复点击受到页面锁定/请求合并约束，不形成高频请求风暴，也不覆盖新页面状态。
  7. 每次重试仍先复核当前资格；若重试期间资格变为未知、撤回或下架，应转为 `PUBLIC_RESOURCE_UNAVAILABLE`/404 并隐藏全部受影响媒体，而不是继续按媒体 503 处理。
- **证据要求**：资格确认事件；聚合 `OK/200` 与独立媒体 `PUBLIC_MEDIA_UNAVAILABLE/503` 的成对脱敏响应；页面降级和单项重试录屏；媒体顺序对照；`no-store` 响应头；敏感地址/异常哨兵未出现检查；快速重试请求次数与 `requestId` 记录。
- **阻塞/待决条件**：可选媒体缺失的最终 DTO 表达、安全占位视觉和必需封面失败策略仍待评审；这些不阻塞“可选单项失败时聚合 200、独立网关 503、不泄露地址”的已锁定语义。媒体故障注入未就绪时执行阻塞。
- **初始执行状态**：`NOT_RUN`

### S1-WORK-06 固定 ID/对象注入

- **用例 ID**：`S1-WORK-06`
- **名称**：修改路由 ID、分享对象和媒体参数不能绕过服务端当前资格与发布状态
- **优先级**：P0
- **类型/建议测试层**：对象级授权与输入注入安全；领域/查询集成 + 接口安全 + 页面/真机深链
- **规则来源**：D-702 §3.3 `S1-WORK-06`；D-401 §2、§4、§5、§7、§9；D-602 §2、§5、§7；A15 §11；D-701 §3
- **前置条件**：
  1. 准备五个不透明公开标识：合格公开作品、未发布作品、资格未知作品、授权撤回作品、已下架作品；另准备不存在和格式非法/过长标识。
  2. 为不合格作品准备客户端伪造完整对象，含 `published=true`、`authorized=true`、`visible=true`、合格作品价格/标题及伪造媒体地址。
  3. 准备一条合格作品分享入口和媒体网关引用，可修改其中资源 ID、媒体 ID、变体、用途或所属资源参数；具体参数按最终契约映射。
  4. 可观察服务端查询与媒体资格检查，确认不是客户端自行判断。
- **测试数据**：`合格作品公开标识`、`未发布作品公开标识`、`资格未知作品公开标识`、`授权撤回作品公开标识`、`已下架作品公开标识`、`不存在作品公开标识`、`非法与过长作品标识`、`伪造已发布已授权客户端对象`
- **步骤**：
  1. 用合格公开标识打开详情，记录正常基准和受控媒体引用。
  2. 依次把路由/请求标识替换为未发布、资格未知、授权撤回、已下架和不存在作品标识，同时携带伪造完整对象。
  3. 分别提交格式非法和超过已锁定上限的作品标识。
  4. 修改分享载荷中的标题、媒体、`published`、`authorized`、`visible` 等字段，只保留或替换资源标识后打开入口。
  5. 在媒体网关请求中交叉替换作品 ID、媒体 ID、用途和变体，尝试读取未绑定媒体、其他作品媒体和私密媒体哨兵。
  6. 对不合格资源尝试 304、Range、旧 URL、本地缓存和并发重复请求。
  7. 比较各公开错误响应，并检查是否泄露某一标识存在、内部状态、客户、授权或存储信息。
- **预期结果**：
  1. 合格作品仍由服务端按公开标识查询并完成当前资格校验，客户端对象只用于导航展示的任何非权威部分都不能决定资格。
  2. 未发布、资格未知、撤回、下架和不存在资源统一返回 `PUBLIC_RESOURCE_UNAVAILABLE`/404；伪造 `published/authorized/visible` 和媒体地址不改变结果。
  3. 非法或过长标识返回 `PUBLIC_QUERY_INVALID`/400；错误不触发内部异常泄漏或无限查询。
  4. 分享载荷被篡改时，服务端当前查询结果覆盖客户端标题、媒体和资格字段；不显示伪造对象，也不依赖发送设备登录态。
  5. 媒体网关校验所属资源、媒体绑定、用途和变体；交叉对象、未绑定、其他作品及私密媒体请求均拒绝，不能仅凭媒体 ID 或 URL 访问。
  6. 304、Range、旧 URL、本地缓存和重复请求不绕过服务端当前资格；媒体与错误响应 `no-store`，重复请求不产生公开资格或授权副作用。
  7. 不合格/不存在状态在匿名端不可枚举；公开响应、响应头、URL 和页面不泄露客户资料、授权证据、原始 key、供应商信息或内部原因。
- **证据要求**：正常基准与所有负向标识的参数化执行记录；路由/分享对象篡改前后录屏；详情与媒体网关脱敏请求/响应/响应头；服务端资格和绑定检查记录；`PUBLIC_QUERY_INVALID`/400 与 `PUBLIC_RESOURCE_UNAVAILABLE`/404 对照；敏感哨兵未出现检查；重复请求副作用为零的可观察证据。
- **阻塞/待决条件**：公开 ID 字符集/长度、分享载荷、媒体网关参数和实际路径尚待契约锁定时，精确输入值执行阻塞；服务端必须忽略客户端资格字段、详情重查和媒体对象绑定复核的安全断言不阻塞。不得猜测现有控制器或表字段实施注入。
- **初始执行状态**：`NOT_RUN`

## 5. 总体阻塞与待决条件

1. 阶段一公开数据的受控发布、下架、A15 资格输入和授权撤回流程未实现时，状态转换执行阻塞；不得直接修改假定的数据库字段伪造正式动作。
2. D-401 的稳定错误码及 HTTP 映射已经锁定；路径、DTO、公开 ID 格式、分享参数和媒体网关参数仍是草案。精确脚本等待契约锁定，但统一不可用、服务端 fail-closed、数据最小化和对象绑定校验不得放宽。
3. SouthLeaf 受控媒体网关的生产域名、缩略图/预览参数和对象存储适配尚待评审；不得退回供应商直链、公共桶地址、永久签名或原始 key。网关未就绪时媒体相关用例保持阻塞而非标记通过。
4. 作品媒体 `Cache-Control: no-store`、不支持借 304/Range 绕过、每次展示前当前资格复核是锁定规则，不属于待确认项。实现不具备这些能力时应记录阻塞/缺陷，不能以缓存 TTL 待定为由豁免。
5. 普通文字投影 TTL、ETag 取值、缓存传播目标及撤回后的目标时限仍待评审。可记录实际时间，但不能声称达到未定义 SLA；已知撤回、下架或资格未知后仍必须立即以当前事实拒绝。
6. A15 的授权证据形式、儿童/多人/监护关系核验细则仍待经营确认。任何无法证明有效和范围匹配的资格均 fail-closed，不得把待确认证明为可公开。
7. 可选媒体缺失的最终 DTO 表达、安全占位视觉和必需封面失败策略待评审；`OK/200` 聚合与独立媒体 `PUBLIC_MEDIA_UNAVAILABLE/503` 的边界已锁定，不得混用。
8. 服务端资格判断、媒体绑定复核、缓存任务状态、响应头和 `requestId` 的观测能力未就绪时，P0 结果判定阻塞；页面截图和客户端日志不能替代服务端证据。
9. 本文件 6 个主用例及其全部变体保持 `NOT_RUN`，直至使用候选版本完成独立执行、保存脱敏证据并评审。文档完成、桌面推演或合成数据准备不代表产品测试通过。
