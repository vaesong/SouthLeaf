# 阶段一公开依赖故障与恢复详细测试用例

> 文档编号：D-716  
> 文档状态：评审中  
> 适用范围：阶段一  
> 更新日期：2026-10-09  
> 上游需求：A04-A06、A10、A12-A16  
> 上游架构：AT04、AT06、AT08-AT09  
> 关联计划：P01  
> 场景来源：D-704 §4 `S1-FAULT-01`～`S1-FAULT-08`  
> 关联设计：D-702、D-401、D-602、D-700、D-701  
> 初始执行状态：`NOT_RUN`

## 1. 覆盖摘要

本文将 D-704 §4 的阶段一八类故障逐项落实为 8 个 `FAULT` 主用例：导入/登记中断；文件/元数据校验失败；外部对象与本地登记不一致；预览/缩略图失败；公开版本更新重复/响应丢失；授权资格读取超时/未知；撤回后下架任务失败；下架/替换后的缓存与旧链接。

| 用例范围 | 主用例数 | 共同观察面 | 初始状态 |
|---|---:|---|---|
| `S1-FAULT-01`～`S1-FAULT-08` | 8 | 权威业务事实、对外公开结果、外部调用次数、逻辑幂等结果、任务状态、脱敏日志、逻辑审计、有限重试、恢复与人工处理 | `NOT_RUN` |

共同执行原则：

- 测试使用可控外部依赖替身和合成媒体，不锁定对象存储、媒体处理、缓存或其他供应商。
- 每个故障变体分别记录外部**物理调用次数**和最终**逻辑业务结果**。允许重试产生多次执行日志，但不得产生重复公开媒体、重复公开版本或重复逻辑业务审计事件。
- 仅对明确可重试的暂时错误进行有限重试；永久校验失败、数据不匹配或无法安全判定的结果进入待人工处理。禁止无限重试。
- 最大重试次数、退避、任务超时、人工升级责任和传播时限未确认，涉及具体数值/时限的断言标为 `BLOCKED`；这不阻碍“不得公开未完成/未知/已撤回内容”等安全断言。
- 受控导入/更新流程、任务名称、幂等键字段和审计事件结构仍需实现设计锁定；用例以业务意图和可观察结果描述，不预设数据库表或供应商字段。
- 本文只定义用例，尚未执行，不产生通过结论。

## 2. 详细用例

### S1-FAULT-01 受控导入或对象登记中断

- **用例 ID**：`S1-FAULT-01`
- **名称**：导入/登记各中断点保持媒体未完成且不可公开
- **优先级**：P0
- **类型/建议测试层**：故障注入 + 恢复；应用服务集成、任务执行器、存储替身、公开接口
- **规则来源**：D-704 §3、§4 第 1 项、§6、§7；D-702 §3.3、§6；D-401 §4；D-701 §4、§6；P01 §3.3
- **前置条件**：
  - 存在受控公开数据导入/更新入口；操作者已通过该流程所需的受控授权，阶段一不要求交付管理后台。
  - 初始无目标公开媒体、公开投影或公开版本引用。
  - 可观察外部对象写入、元数据登记、任务、日志、逻辑审计和公开查询。
- **测试数据/故障注入**：
  - 导入意图 `import_fault_01`，使用自有合成图片和稳定业务幂等标识。
  - 中断点变体：外部写入前进程中断；外部写入成功后本地登记前中断；本地未完成登记后发布投影前中断；任务状态落库前响应丢失；服务重启。
- **步骤**：
  1. 记录目标资源、媒体登记、公开投影、版本、任务和审计基线。
  2. 从独立基线分别在每个中断点执行同一导入意图，并记录外部调用次数和已落地事实。
  3. 中断期间匿名请求首页、列表、详情及可能的媒体引用。
  4. 重启服务，使用相同业务意图/幂等标识恢复或重投任务。
  5. 对可自动恢复变体等待任务收敛；对无法安全收敛变体进入人工核验并记录处理结果。
  6. 比较最终媒体登记、公开投影、版本、任务日志和逻辑审计数量。
- **可观察预期**：
  - 中断期间媒体保持未完成/待处理或等价非公开状态，不进入公开投影，公开查询和媒体网关均不返回。
  - 外部写入成功而本地未登记时不伪造完成；恢复后核验外部事实再收敛，不盲目创建第二个逻辑媒体。
  - 使用同一幂等意图恢复后最多形成一个逻辑媒体登记和一个对应公开结果；物理重试次数与执行日志可多次记录。
  - 任务保留当前状态、最后脱敏错误、尝试记录和下一步；无法自动判定时进入人工处理，不无限重试。
  - 原始失败/中断记录保留，恢复不删除审计链。
- **证据要求**：
  - 每个中断点的业务事实快照、外部对象状态、公开查询结果和时间线。
  - 外部调用次数、幂等标识、媒体/版本数量及任务执行日志。
  - 脱敏错误、逻辑审计和人工处理记录；恢复前后对照。
- **阻塞/待决条件**：
  - 受控导入流程、任务状态名、幂等键字段、外部对象核验方式和人工操作载体尚需设计锁定。
  - **BLOCKED（参数断言）**：最大重试次数、退避、任务超时和升级时限未确认。
  - 不阻塞“未完成不得公开、恢复不得重复媒体事实、失败必须可追踪”的安全断言。
- **初始执行状态**：`NOT_RUN`

### S1-FAULT-02 文件或必要元数据校验失败

- **用例 ID**：`S1-FAULT-02`
- **名称**：类型、尺寸、完整性及必要元数据失败时拒绝进入公开数据源
- **优先级**：P0
- **类型/建议测试层**：参数化校验 + 安全；校验规则单元、导入集成、公开接口
- **规则来源**：D-704 §4 第 2 项、§6；D-401 §2、§4；D-701 §4、§8
- **前置条件**：
  - 文件与元数据校验发生在形成可公开媒体事实之前。
  - 可独立观察原始导入意图、校验结果、任务状态、日志和公开投影。
- **测试数据/故障注入**：
  - 变体：不允许的文件类型；声明类型与内容不符；文件截断/校验和不符；零字节；尺寸或必要尺寸元数据无效；必要归属/用途/排序元数据缺失；元数据关联到另一公开资源。
  - 文件名、内部路径和元数据中写入 `S1_FAULT_02_SENSITIVE_SENTINEL`。
  - 同一失败输入重复提交一次，再提交修复后的新有效输入。
- **步骤**：
  1. 对每个变体从干净基线提交导入，记录校验阶段前后的外部调用和本地事实。
  2. 查询首页、列表、详情、公开投影和媒体网关，确认失败资源不可见。
  3. 使用相同业务意图重复提交失败输入，记录任务、调用和审计变化。
  4. 检索公开响应、运维错误日志和审计，检查敏感哨兵、路径和供应商信息。
  5. 按受控流程提交修复后的有效输入，确认新意图经过完整校验后才可进入后续发布流程。
- **可观察预期**：
  - 每个校验失败均被明确拒绝，文件和元数据不形成可公开媒体或公开投影引用。
  - 永久校验失败不自动无限重试；重复同一失败意图不创建多个逻辑媒体或公开版本。
  - 失败记录可通过任务/请求标识追踪，但错误内容脱敏，不向公开端返回文件名、内部路径、对象 key、供应商或哨兵。
  - 修复后的有效输入作为明确的新处理结果通过全部校验后才能发布，不能直接把失败记录改写为已成功而丢失历史。
- **证据要求**：
  - 参数化校验矩阵、每个变体的校验结果和公开不可见证据。
  - 外部调用次数、媒体/投影/版本数量及重复提交的幂等结果。
  - 任务、脱敏日志、逻辑审计、哨兵扫描和修复后新处理链证据。
- **阻塞/待决条件**：
  - **BLOCKED（精确校验值）**：允许文件类型、尺寸上下限、完整性算法、缩略图/预览必要元数据和错误码尚需媒体契约锁定。
  - 不阻塞“不通过必要校验不得公开、永久错误不得无限重试、错误不得泄露敏感信息”的断言。
- **初始执行状态**：`NOT_RUN`

### S1-FAULT-03 外部对象与本地登记不一致

- **用例 ID**：`S1-FAULT-03`
- **名称**：孤立外部对象或不可读本地登记经核验后幂等收敛
- **优先级**：P0
- **类型/建议测试层**：一致性故障 + 对账恢复；应用服务集成、存储替身、任务执行器、公开接口
- **规则来源**：D-704 §3、§4 第 3 项、§6；D-401 §4；D-701 §4、§6
- **前置条件**：
  - 可分别控制外部对象状态和本地媒体登记/公开投影状态。
  - 可运行受控核验/恢复任务并观察对象查询、写入/删除调用、任务与审计。
- **测试数据/故障注入**：
  - 变体 A：外部对象存在，本地无登记。
  - 变体 B：本地登记存在，外部对象不存在。
  - 变体 C：本地登记存在，外部对象暂时不可读/超时。
  - 变体 D：外部对象内容或关联标识与本地登记不匹配。
  - 对每个变体重复投递核验任务，并插入一次服务重启。
- **步骤**：
  1. 建立四种不一致状态并记录基线，确保目标尚未作为合格公开媒体展示。
  2. 在核验前及核验处理中请求公开详情和媒体网关。
  3. 运行核验/恢复任务，记录每次外部检查及变更调用、任务状态和判断结果。
  4. 在首次结果响应丢失后重复同一任务，并在服务重启后再次执行。
  5. 恢复暂时性依赖；对永久缺失/不匹配变体执行受控人工处理。
  6. 核对最终外部对象、本地登记、公开投影、媒体记录和审计事件数量。
- **可观察预期**：
  - 无法证明外部对象与本地登记一致、可读且归属正确前，不得进入公开投影或由媒体网关返回。
  - 暂时不可读与明确不存在/不匹配分别处理；前者可有限重试，后者进入人工处理或已评审补偿，不盲目重建/删除。
  - 重复核验和重启恢复后最多形成一个逻辑媒体事实，不创建重复登记、重复公开引用或重复逻辑审计事件。
  - 外部调用次数、判断结果、任务状态和最后错误可追踪；公开响应不暴露对象存储状态或供应商信息。
- **证据要求**：
  - 四种不一致基线与最终收敛状态、公开查询/媒体拒绝结果。
  - 外部读写调用次数、幂等标识、媒体/引用/审计数量对照。
  - 任务状态、执行日志、脱敏错误和人工处理记录。
- **阻塞/待决条件**：
  - 外部对象核验 API、孤立对象保留/清理策略、永久缺失的补偿动作及供应商能力未确认；本用例不得据此要求删除对象。
  - **BLOCKED（参数断言）**：重试次数、退避和人工升级时限未确认。
  - 不阻塞一致性未证明前不得公开及重复恢复不得创建重复逻辑事实的断言。
- **初始执行状态**：`NOT_RUN`

### S1-FAULT-04 预览或缩略图生成/读取失败

- **用例 ID**：`S1-FAULT-04`
- **名称**：预览/缩略图失败时遵守必需性与安全降级边界
- **优先级**：P0
- **类型/建议测试层**：依赖故障 + 局部降级；媒体处理集成、接口契约、页面集成
- **规则来源**：D-704 §4 第 4 项、§6；D-702 §3.3 `S1-WORK-05`、§5 `S1-STATE-08`；D-401 §3.3、§7；D-602 §4
- **前置条件**：
  - 作品资格已确认有效，原始测试媒体已受控登记。
  - 可分别控制缩略图生成、预览生成和受控媒体网关读取结果。
  - 测试前标注每个媒体变体在待评审契约中是必需还是可选；若尚未决定，仅执行共同安全断言。
- **测试数据/故障注入**：
  - 变体：生成超时、明确拒绝、返回格式错误、响应丢失、重复回调、生成成功但网关读取 503。
  - 返回中包含伪造供应商直链、原始对象 key 和 `S1_FAULT_04_URL_SENTINEL`。
- **步骤**：
  1. 对缩略图和预览分别注入各故障，记录外部调用、处理任务和媒体登记状态。
  2. 在处理未完成/失败时请求首页、列表、详情和独立媒体网关。
  3. 检查 JSON 聚合响应的 HTTP/错误码及可选媒体字段表达，再检查独立网关响应。
  4. 重复同一处理任务并模拟响应丢失后的恢复。
  5. 恢复依赖并重新读取页面，核对最终媒体记录和逻辑审计。
- **可观察预期**：
  - 任何失败路径均不得返回错误文件地址、供应商直链、永久签名地址、原始 key 或哨兵。
  - 若失败媒体属于可选项且主资源仍可用，聚合响应保持 `OK`/200，并按锁定契约省略/标记该项；不得把同一聚合结果解释为 503。
  - 若是资格已确认后的独立媒体读取失败，网关返回 `PUBLIC_MEDIA_UNAVAILABLE`/HTTP 503；资格未知不走此降级，必须 fail-closed。
  - 必需封面/区块是否过滤或整体失败按评审契约执行；契约未锁定时只断言不能展示错误地址或未经确认媒体。
  - 重复处理最多形成一个逻辑媒体变体和一个逻辑审计结果，故障可有限重试或人工处理。
- **证据要求**：
  - 各故障的外部调用次数、任务日志、媒体登记和最终幂等结果。
  - 聚合 JSON 与独立媒体响应、HTTP/错误码、页面局部状态及资格确认记录。
  - URL/响应/日志敏感哨兵扫描和恢复后媒体数量对照。
- **阻塞/待决条件**：
  - **BLOCKED（业务降级断言）**：阶段一是否采用缩略图、哪些媒体/封面是必需项、最终部分成功 DTO 与页面视觉尚需评审。
  - **BLOCKED（参数断言）**：生成/读取超时、重试次数和退避未确认。
  - 不阻塞禁止错误地址/供应商信息泄露、资格未知 fail-closed、重复处理不重复媒体事实的断言。
- **初始执行状态**：`NOT_RUN`

### S1-FAULT-05 公开版本更新重复或成功响应丢失

- **用例 ID**：`S1-FAULT-05`
- **名称**：公开版本更新在重复投递和响应丢失下保持逻辑幂等
- **优先级**：P1
- **类型/建议测试层**：幂等 + 结果未知；应用服务、任务执行器、持久化集成、公开接口
- **规则来源**：D-704 §3、§4 第 5 项、§6；D-702 §6 `S1-CACHE-04`；D-401 §6.1；D-701 §6
- **前置条件**：
  - 公开版本 V1 已稳定，受控流程可提交 V2 更新意图。
  - 可观察版本记录、公开投影、媒体绑定、缓存失效任务、外部调用、执行日志和逻辑审计。
- **测试数据/故障注入**：
  - 更新意图 `publish_fault_05`，具有稳定业务幂等标识。
  - 变体 A：同一任务重复投递。
  - 变体 B：V2 已提交成功但响应丢失，调用方将结果视为未知后重试。
  - 变体 C：首个执行延迟返回，与重试并发完成。
  - 变体 D：成功后服务重启再投递。
- **步骤**：
  1. 记录 V1 的版本、投影、媒体、缓存任务和审计基线。
  2. 对变体 A～D 从独立 V1 基线执行相同 V2 更新意图，记录每次物理调用和任务执行。
  3. 在结果未知时不创建新的更新意图，而用相同幂等标识查询/重试原意图。
  4. 读取最终公开版本、投影、媒体绑定、缓存任务和审计记录。
  5. 从客户端请求当前内容，确认只观察到一个一致的 V2 逻辑结果。
- **可观察预期**：
  - 所有重复、并发、响应丢失和重启变体最终只形成一个 V2 逻辑版本，不出现 V2a/V2b 等重复版本。
  - 不重复创建公开投影、媒体绑定、缓存失效业务意图或逻辑审计事件；可保留每次物理执行日志和调用次数。
  - 结果未知通过原意图核验/重试收敛，不把超时当作失败后创建新的业务意图。
  - 客户端最终得到一致的当前版本；作品媒体仍独立执行当前资格复核，不能因 V2 缓存命中跳过。
- **证据要求**：
  - 四个变体的幂等标识、物理调用次数、并发/返回顺序和任务执行日志。
  - 版本、投影、媒体、缓存任务和逻辑审计的前后数量对照。
  - 客户端最终响应、版本标识及媒体资格复核证据。
- **阻塞/待决条件**：
  - 更新入口/任务名称、幂等键字段、版本生成规则、审计事件结构和结果查询方式尚需设计锁定。
  - **BLOCKED（参数断言）**：请求超时、最大重试次数、退避和任务完成时限未确认。
  - 不阻塞同一更新意图只有一个逻辑版本/事件结果的断言。
- **初始执行状态**：`NOT_RUN`

### S1-FAULT-06 授权资格读取超时或结果未知

- **用例 ID**：`S1-FAULT-06`
- **名称**：资格依赖超时、未知或格式异常时 fail-closed 并可恢复
- **优先级**：P0
- **类型/建议测试层**：安全故障 + 恢复；领域/应用服务、接口、媒体网关、页面集成
- **规则来源**：D-704 §4 第 6 项、§6、§7；D-702 §3.3、§6 安全默认；D-401 §4、§6.1、§7；D-602 §4、§5、§7；D-701 §1、§6
- **前置条件**：
  - 作品曾满足公开资格并可能存在旧页面状态/媒体引用。
  - 资格依赖可返回连接超时、响应超时、未知、缺字段、关联标识不匹配及恢复后的有效结果。
  - 可观察资格调用、公开查询、媒体网关、页面、任务/日志和审计。
- **测试数据/故障注入**：
  - 作品 `work_fault_06`，旧媒体引用 `media_fault_06`。
  - 故障变体：连接失败、超时、明确 `UNKNOWN`、格式错误、资源/资格关联 ID 不匹配、迟到“有效”响应与新请求交错。
- **步骤**：
  1. 在资格有效时读取一次作品，保存旧详情和媒体引用，然后清理任何不允许持久缓存的作品媒体。
  2. 逐一注入资格故障并请求首页、列表、详情和旧媒体引用。
  3. 在页面恢复、分享入口和快速重试场景重复请求，记录资格依赖调用次数和旧响应处理。
  4. 先让新请求得到未知/不可用，再返回旧请求的迟到有效响应，观察页面和公开结果。
  5. 恢复资格依赖并返回当前有效结果，重新请求；另从独立基线恢复为明确无资格结果。
- **可观察预期**：
  - 资格无法证明时一律按不具备公开资格处理：列表/首页不返回，详情和媒体网关拒绝，页面不显示旧作品图片。
  - 公开端统一为 `PUBLIC_RESOURCE_UNAVAILABLE`/HTTP 404，不暴露是超时、未知、格式错误或 ID 不匹配；不得误用 `PUBLIC_MEDIA_UNAVAILABLE`。
  - 迟到的旧有效响应不覆盖新请求的不可用状态；恢复后仅以当前资格结果决定是否重新展示。
  - 暂时错误可有限重试，永久数据不匹配进入人工处理；所有调用、任务/日志和逻辑审计可追踪且脱敏。
- **证据要求**：
  - 每个资格故障的调用次数、返回顺序、公开接口/媒体响应和页面状态。
  - 旧响应不覆盖、新请求恢复及明确无资格的对照时间线。
  - requestId/任务标识、脱敏日志、逻辑审计和人工处理记录。
- **阻塞/待决条件**：
  - 资格通过同步内部端口还是本地可核验快照、接口字段、错误细分和观测方式尚需设计锁定。
  - **BLOCKED（参数断言）**：资格读取超时值、重试次数、退避和恢复时限未确认。
  - 不阻塞资格未知 fail-closed、旧图不可恢复、公开原因不可枚举和旧响应不得覆盖的安全断言。
- **初始执行状态**：`NOT_RUN`

### S1-FAULT-07 授权撤回后下架任务失败

- **用例 ID**：`S1-FAULT-07`
- **名称**：撤回事实已成立但投影/缓存下架任务失败时仍停止公开
- **优先级**：P0
- **类型/建议测试层**：跨模块安全 + 补偿；应用服务、任务执行器、公开接口、媒体网关、页面/真机
- **规则来源**：D-704 §4 第 7 项、§6、§7；D-702 §3.3、§6；D-401 §4、§6.1；D-602 §5、§7；D-701 §6；P01 §3.3、§3.5
- **前置条件**：
  - 作品当前已发布且授权资格有效，首页、列表、详情及媒体均可访问。
  - 可执行 A15 授权撤回并确认权威撤回事实独立于下架任务成立。
  - 可在投影移除、首页编排更新、缓存失效或媒体引用失效阶段注入失败。
- **测试数据/故障注入**：
  - 作品 `work_fault_07`、媒体 `media_fault_07`，预先保存旧链接与旧引用。
  - 故障变体：任务连接失败、处理超时、写入失败、任务状态更新前进程中断、响应丢失后重复投递。
  - 日志内部原因含 `S1_FAULT_07_REVOKE_REASON_SENTINEL`。
- **步骤**：
  1. 记录撤回前的公开结果、版本、媒体引用、任务和审计基线。
  2. 执行授权撤回，确认权威撤回事实已提交，然后在各下架阶段注入故障。
  3. 在任务失败期间请求首页、列表、详情、旧链接、旧媒体引用，并从后台恢复及另一设备复查。
  4. 重复投递同一下架意图，记录外部/内部调用次数、幂等结果和任务状态。
  5. 恢复依赖或执行受控人工补偿，确认任务最终收敛并保留原始失败记录。
  6. 扫描公开响应、页面和日志，确认撤回原因哨兵未向公开端泄露。
- **可观察预期**：
  - 撤回事实成立后，公开查询与媒体网关必须按当前资格拒绝，不等待投影/缓存任务成功；已知不合格作品不继续暴露。
  - 首页/列表不返回，详情/旧链接统一不可用，旧媒体引用、设备缓存、后台恢复和另一设备均不能恢复图片。
  - 重复下架任务只形成一个逻辑下架结果和一个逻辑审计事件；物理重试及失败日志可多次记录。
  - 任务显示失败/待重试/待人工或等价状态，错误脱敏；有限重试后可人工处理，撤回事实和原始失败历史不被回滚/删除。
- **证据要求**：
  - 撤回事实提交与各下架故障点、公开拒绝结果的联合时间线。
  - 首页/列表/详情/旧媒体/后台恢复/跨设备证据。
  - 调用次数、幂等标识、任务日志、逻辑审计、人工处理及敏感哨兵扫描结果。
- **阻塞/待决条件**：
  - 下架任务拆分方式、状态名、人工处理载体和审计事件结构尚需实现设计锁定。
  - **BLOCKED（参数/时限断言）**：最大重试、退避、升级责任和投影/缓存传播时限未确认。
  - 不阻塞撤回后查询与媒体立即按当前事实拒绝、任务失败不得恢复公开等 P0 安全断言。
- **初始执行状态**：`NOT_RUN`

### S1-FAULT-08 下架或替换后的缓存与旧链接

- **用例 ID**：`S1-FAULT-08`
- **名称**：下架、媒体替换和公开引用删除后旧缓存/旧链接不泄露
- **优先级**：P0
- **类型/建议测试层**：缓存安全 + 深链恢复；接口、受控媒体网关、页面、微信目标环境/真机
- **规则来源**：D-704 §4 第 8 项、§6；D-702 §3.3、§6；D-401 §4、§6.1、§7；D-602 §5、§7、§8；D-701 §3、§5、§6
- **前置条件**：
  - 作品 V1 当前公开，至少在两个设备访问过首页、列表、详情和分享链接。
  - 保存 V1 的普通文字版本、详情旧链接、媒体旧 URL、可能的 Range 请求上下文及本地缓存状态。
  - 可执行作品下架、媒体 V1→V2 替换和公开引用删除三种独立操作。
- **测试数据/故障注入**：
  - 变体 A：作品整体下架。
  - 变体 B：作品仍可公开，但媒体 V1 被 V2 替换。
  - 变体 C：从公开内容删除媒体引用。
  - 每个变体注入缓存失效延迟/失败；尝试旧 URL、304 条件请求、Range、离线本地文件、后台恢复、分享/扫码和跨设备访问。
- **步骤**：
  1. 在变更前从两设备加载 V1，记录所有入口、版本、响应头和旧媒体引用。
  2. 从独立基线分别执行 A、B、C，并使缓存失效任务延迟或失败。
  3. 立即访问首页、列表、详情、分享旧链接及旧媒体 URL，并尝试 `If-None-Match`/304、Range 和本地缓存命中。
  4. 执行 Tab 返回、后台恢复、清理应用缓存后重入及第二设备访问。
  5. 恢复失效任务或人工补偿，再次检查当前 V2/不可用结果及任务、日志和审计。
- **可观察预期**：
  - 作品整体下架时：首页/列表移除，详情与分享旧链接统一不可用，不泄露下架原因、客户或授权信息。
  - 媒体替换时：旧 V1 引用不再返回旧媒体；当前资格和绑定有效时仅 V2 可经受控媒体网关读取。
  - 删除公开引用时：旧媒体 URL 不因对象仍存在而继续公开；外部对象物理删除不作为本用例默认要求。
  - 作品媒体保持 `no-store`，304、Range、本地文件、旧 URL、后台恢复和跨设备均不能绕过当前发布、绑定及资格检查。
  - 缓存失效任务失败有可追踪状态、有限重试和人工处理；无重复逻辑下架/替换结果或逻辑审计事件。
- **证据要求**：
  - A/B/C 三类变更前后首页、列表、详情、分享链接及媒体响应对照。
  - 304、Range、本地命中、后台恢复、清缓存和双设备测试记录。
  - 调用次数、任务状态、脱敏日志、逻辑审计、幂等结果及恢复/人工处理证据。
- **阻塞/待决条件**：
  - **BLOCKED（时限断言）**：缓存/CDN 失效传播目标和旧引用保留期限未确认。
  - **BLOCKED（实现参数）**：具体缓存供应商、媒体域名、ETag 生成和对象存储删除/保留策略未确认；不得假定供应商能力或要求物理删除。
  - 不阻塞旧链接安全不可用、旧媒体引用不得返回、媒体 no-store 和每次读取资格/绑定复核的安全断言。
- **初始执行状态**：`NOT_RUN`

## 4. 共同证据清单

每个 `FAULT` 主用例及其故障变体至少保留以下证据，缺少任一关键观察面不得填写通过：

1. 故障注入点、初始权威事实、外部依赖替身配置和恢复动作。
2. 公开接口、受控媒体网关及页面对外结果，包含 `requestId` 或任务标识。
3. 每种外部操作的物理调用次数、调用顺序、响应/超时/丢失情况。
4. 最终逻辑媒体、公开版本、投影、下架/替换结果及逻辑审计事件数量。
5. 任务状态、尝试记录、最后脱敏错误、下一步处理和服务重启后的续跑结果。
6. 自动重试与人工处理记录；人工动作包含授权角色、原因、操作者、时间、影响和结果，但不记录真实凭证或客户资料。
7. 日志/响应/URL 敏感扫描结果，证明未泄露客户信息、授权证据、对象 key、供应商凭证、完整签名 URL 或内部堆栈。

## 5. 阻塞条件汇总

1. **依赖与供应商**：对象存储、媒体处理和缓存供应商未定；所有用例按能力与不变量编写，不锁定供应商 API、错误码或 SLA。
2. **受控运维流程**：阶段一公开数据导入、发布、撤回、人工复核的具体工具和责任分工未确认；执行前需提供可审计的受控入口，但不因此要求阶段一管理后台。
3. **任务参数**：最大重试次数、退避、超时、死信/待人工状态名和升级责任未确认。相关数值断言统一为 `BLOCKED`，但禁止无限重试、暂时/永久错误分流和人工处理可达仍须验证。
4. **传播时限**：投影、缓存和旧链接失效目标未确认，不能声称在某个具体时限内完成；撤回/下架事实成立后公开查询和媒体网关必须基于当前事实拒绝，不受传播时限待决影响。
5. **媒体契约**：是否采用缩略图、媒体变体必需性、尺寸/类型/完整性规则、受控媒体生产域名和部分成功 DTO 尚需锁定；禁止错误地址、供应商直链、原始 key 及未经资格确认媒体公开不受阻塞。
6. **资格读取契约**：同步端口或本地快照模式未定；任何未知、超时、格式错误或无法证明的资格结果均 fail-closed。
7. **执行环境**：需具备可控故障替身、进程中断/重启、响应丢失/重复/乱序、任务与审计查询、双设备或等价隔离客户端。环境缺失只标阻塞，不得推定通过。

本文件 8 个主用例当前均为 `NOT_RUN`；未确认的重试次数和传播时限只阻塞对应数值断言，不阻碍 P0 安全断言执行与缺陷判定。
