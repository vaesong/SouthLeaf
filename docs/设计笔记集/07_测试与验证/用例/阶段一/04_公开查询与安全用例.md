## 1. 覆盖摘要

本文把 D-702 §4 的 8 个公开查询场景逐个细化为可执行主用例，验证匿名只读查询、公开资格过滤、错误码与 HTTP 映射、公开字段白名单、内部敏感哨兵、稳定分页、详情二次校验、`requestId` 关联以及生产 HTTPS/合法域名边界。

| 用例范围 | 主用例数 | 重点风险 | 初始状态 |
|---|---:|---|---|
| `S1-API-01`～`S1-API-08` | 8 | 未发布或无资格内容泄露、敏感字段泄露、枚举内部状态、分页漂移、旧链接绕过、错误不可追踪、生产环境错误域名 | `NOT_RUN` |

执行约束：

- D-401 §3.1 所列 `/api/v1/public/...` 仅作为当前路径草案，用于定位待测能力；实际 API 前缀、版本、资源路径和参数名需在接口契约评审后锁定。
- D-401 §3.2～§3.3 所列响应外层和 DTO 字段是当前草案。字段白名单测试先验证“禁止字段与敏感哨兵绝不出现”；精确到每个允许字段、必填性和可空性的兼容断言在契约锁定后启用。
- D-401 §7 当前定义的稳定错误码与 HTTP 映射纳入测试设计；若统一响应契约评审导致调整，应先同步 D-401、D-602 和本文件，再执行精确契约断言，不以测试文件单独锁定新映射。
- 所有数据使用合成公开资料和自有测试媒体，不使用真实客户信息、真实授权证据或生产密钥。
- 本文只定义用例，尚未执行，不产生通过结论。

## 2. 详细用例

### S1-API-01 首页聚合仅返回当前可公开内容

- **用例 ID**：`S1-API-01`
- **名称**：首页聚合的发布、资格、字段范围与只读性
- **优先级**：P0
- **类型/建议测试层**：正向 + 安全；接口契约、应用服务集成、公开投影集成
- **规则来源**：D-702 §4 `S1-API-01`；D-401 §1、§2、§3.1、§4、§9；D-701 §3；P01 §3.3、§3.5
- **前置条件**：
  - 隔离环境存在同一批次的品牌、业务、套餐和作品数据。
  - 数据集中同时包含：已发布且资格有效、草稿、已下架、资格未知、授权已撤回、已过期六类资源。
  - 首页编排同时引用上述作品，并包含已确认与未确认的品牌/联系字段。
  - 可读取公开投影、请求日志及业务事实计数，调用前记录预约、订单、支付和授权事实基线。
- **测试数据/故障注入**：
  - 合格作品 `work_api_01_ok`，资格为有效且媒体绑定有效。
  - 不合格作品分别为 `work_api_01_draft`、`work_api_01_offline`、`work_api_01_unknown`、`work_api_01_revoked`、`work_api_01_expired`。
  - 在未确认联系字段和内部编排备注中写入批次唯一哨兵 `S1_API_01_INTERNAL_SENTINEL`。
  - 无故障注入。
- **步骤**：
  1. 记录公开投影版本、各类业务事实数量及本批次资源状态。
  2. 匿名请求首页聚合能力；实际路径使用契约锁定后的路径，当前草案为 `GET /api/v1/public/home`。
  3. 保存 HTTP 状态、响应头、完整响应体和 `requestId`，解析品牌、精选作品、业务、套餐及联系摘要。
  4. 分别用各资源公开 ID 搜索响应体，核对首页编排顺序和关联标识。
  5. 再次读取预约、订单、支付、授权事实及公开版本，比较调用前后差异。
- **可观察预期**：
  - 返回 `OK`/HTTP 200；仅包含已发布且当前资格有效的资源，`work_api_01_ok` 可出现，其余五类作品均不出现。
  - 未确认联系字段和 `S1_API_01_INTERNAL_SENTINEL` 不出现在响应体、响应头或媒体引用中。
  - 首页各区块数量受服务端上限约束，不通过无限制全量数据拼接响应。
  - 响应只包含当前公开 DTO 允许表达的摘要；不返回草稿状态、内部审核/授权原因或客户事实。
  - 查询不创建或修改预约、订单、支付、授权等业务事实；允许新增脱敏访问日志和技术指标。
- **证据要求**：
  - 请求与响应原文、响应头、`requestId` 对应的脱敏服务端日志。
  - 测试数据状态清单及各公开 ID 在响应中的包含/排除对照。
  - 调用前后业务事实计数和公开版本对比。
- **阻塞/待决条件**：
  - **BLOCKED（精确契约断言）**：首页实际路径、区块字段、必填/可空规则及区块数量上限尚需契约锁定。
  - 不阻塞“仅返回当前合格内容、敏感哨兵不泄露、查询不得创建业务事实”等安全断言。
- **初始执行状态**：`NOT_RUN`

### S1-API-02 列表分页、筛选和稳定排序

- **用例 ID**：`S1-API-02`
- **名称**：公开列表分页边界、筛选隔离与稳定结果
- **优先级**：P1
- **类型/建议测试层**：边界 + 参数化 + 一致性；接口契约、数据库/公开投影集成
- **规则来源**：D-702 §4 `S1-API-02`；D-401 §5、§9；D-701 §3
- **前置条件**：
  - 创建不少于两个分页的数据量，全部使用同一公开版本。
  - 同一排序主值下至少存在 4 条资源，以验证稳定的次级排序；其中混入已下架、资格未知和其他业务分类资源。
  - 测试期间冻结该数据集的发布更新，避免把真实并发更新误判为分页漂移。
- **测试数据/故障注入**：
  - 合格资源 `work_api_02_01`～`work_api_02_12`，覆盖两个业务筛选值和相同 `publishedAt`/编排顺序值。
  - 不合格资源 `work_api_02_hidden_*`。
  - 参数变体：默认分页、最小允许数量、最大允许数量、超过上限、有效/非法 `businessId`、有效/非法游标或页码。
  - 无故障注入。
- **步骤**：
  1. 使用默认参数请求作品列表，记录资源 ID 顺序、分页元数据和公开版本。
  2. 沿返回的游标或页码连续读取全部页面，合并资源 ID。
  3. 在数据不变的条件下重复步骤 1～2，并比较每页边界、顺序、重复项和遗漏项。
  4. 对每个有效业务筛选值重复分页，验证分类隔离。
  5. 提交超过数量上限、非法筛选及非法游标/页码，记录错误码、HTTP 状态和响应体。
- **可观察预期**：
  - 同一公开版本和相同参数下，重复读取的顺序与分页边界稳定；无重复、无遗漏，排序主值相同时仍有确定性次序。
  - 每页及合并结果仅包含当前已发布且资格有效的资源；其他分类和不合格资源不越界出现。
  - 服务端限制页大小，客户端不能注入任意数据库排序表达式。
  - 非法或超限参数返回 `PUBLIC_QUERY_INVALID`/HTTP 400，错误体不包含 SQL、字段名、堆栈或内部筛选字典。
- **证据要求**：
  - 两轮完整分页的请求参数、资源 ID 序列、分页元数据和差异结果。
  - 各筛选变体的响应、公开版本及数据基线快照。
  - 非法参数响应和关联的脱敏日志。
- **阻塞/待决条件**：
  - **BLOCKED（精确边界断言）**：最终采用 cursor 还是 page/size、参数名称、默认/最大页大小和稳定排序键尚需契约锁定。
  - 不阻塞无越权结果、服务端必须限量、同一版本结果稳定及非法参数安全失败的断言。
- **初始执行状态**：`NOT_RUN`

### S1-API-03 详情请求执行当前资格二次校验

- **用例 ID**：`S1-API-03`
- **名称**：直接 ID、旧链接和客户端对象不能绕过详情二次校验
- **优先级**：P0
- **类型/建议测试层**：安全 + 状态转换；接口契约、应用服务集成、页面深链联调
- **规则来源**：D-702 §4 `S1-API-03`、§3.3 `S1-WORK-06`；D-401 §2、§4、§5；D-602 §5；D-701 §3
- **前置条件**：
  - 作品 `work_api_03` 初始为已发布、资格有效，可从列表和详情查询。
  - 已保存该作品的公开详情链接、旧列表 DTO 和旧媒体网关引用。
  - 能独立改变发布状态或资格结果，并观察详情资格校验日志。
- **测试数据/故障注入**：
  - 状态变体：下架、授权撤回、资格过期、资格读取返回未知、公开版本替换。
  - 请求注入：直接构造 ID；附加客户端伪造字段 `published=true`、`authorized=true`、`visible=true` 和伪造媒体地址。
- **步骤**：
  1. 在初始合格状态请求列表和详情，保存公开 ID、详情链接、DTO 和媒体引用。
  2. 将作品切换为一个不再可公开的状态，并确认权威事实已更新。
  3. 不重新读取列表，直接打开旧详情链接并请求详情能力。
  4. 使用相同 ID 发起带伪造发布、授权、可见性和媒体字段的请求。
  5. 对其余状态变体分别从独立基线重复步骤 1～4。
- **可观察预期**：
  - 详情以服务端当前事实重新判断，不信任旧列表 DTO、本地对象或客户端传入的状态字段。
  - 下架、撤回、过期、资格未知和版本失效均返回 `PUBLIC_RESOURCE_UNAVAILABLE`/HTTP 404；响应不说明具体内部原因。
  - 响应不返回旧详情、旧媒体引用、客户/授权信息或伪造字段，且错误响应使用 `Cache-Control: no-store`。
  - 服务端日志可通过 `requestId` 证明执行了当前详情资格检查，日志内容保持脱敏。
- **证据要求**：
  - 状态变更前后请求/响应、旧链接和公开 ID 对照。
  - 各状态变体的资格检查日志、`requestId` 和响应头。
  - 伪造字段请求及其未影响结果的证据。
- **阻塞/待决条件**：
  - **BLOCKED（路径与请求形态）**：详情实际路径、公开 ID 格式和是否允许额外查询参数尚需契约锁定。
  - 不阻塞详情必须二次校验、客户端字段无权改变资格及资格未知 fail-closed 的安全断言。
- **初始执行状态**：`NOT_RUN`

### S1-API-04 非法、超长和越界查询参数安全失败

- **用例 ID**：`S1-API-04`
- **名称**：公开查询参数校验与错误码/HTTP 映射
- **优先级**：P0
- **类型/建议测试层**：负向 + 模糊输入 + 边界；接口契约、安全测试
- **规则来源**：D-702 §4 `S1-API-04`；D-401 §5、§7、§9；D-602 §6；D-701 §3
- **前置条件**：
  - 公开查询接口已部署于隔离环境，异常监控和日志可读取。
  - 建立一次合法请求作为响应格式和业务事实基线。
- **测试数据/故障注入**：
  - 参数集包含：空白/非法字符 ID、超长 ID、未知业务字典值、超长标签、负数/零/超过上限数量、畸形游标、重复冲突参数、嵌套编码和排序表达式注入字符串。
  - 哨兵字符串：`S1_API_04_STACK_SQL_PATH_SENTINEL`，用于确认错误回显不会暴露输入上下文或内部实现。
- **步骤**：
  1. 对每个参数变体单独发起请求，保留原始 URL 的脱敏副本及请求序号。
  2. 记录 HTTP 状态、稳定错误码、响应外层、响应头和 `requestId`。
  3. 检索响应体与响应头中是否出现堆栈、数据库/表字段、文件路径、供应商、内部服务名或完整哨兵。
  4. 检查异常日志只保存诊断所需的脱敏信息，并确认请求未触发公开投影或业务事实写入。
  5. 参数批次结束后发起合法请求，确认服务仍可正常响应且未形成请求风暴。
- **可观察预期**：
  - 所有契约定义的非法查询参数稳定返回 `PUBLIC_QUERY_INVALID`/HTTP 400，不因具体非法值变成未处理的 500。
  - 错误响应遵循统一公开外层并带 `requestId`，使用 `Cache-Control: no-store`，不参与 ETag/304 协商。
  - HTTP body、响应头和公开 URL 不泄露堆栈、数据库结构、内部路径、供应商信息或敏感哨兵。
  - 参数不会被当作数据库排序表达式、内部字段或媒体地址执行；无业务写入副作用。
- **证据要求**：
  - 参数化执行清单及每个变体的状态码、错误码、`requestId` 汇总。
  - 代表性原始响应、响应头、脱敏日志与敏感词扫描结果。
  - 执行前后业务事实/公开版本无变化的对照。
- **阻塞/待决条件**：
  - **BLOCKED（精确边界值）**：各参数字符集、长度、页大小上限、重复参数处理规则和实际参数名尚需契约锁定。
  - 已明确的错误脱敏、无写入、不可注入和非法输入不得产生未处理异常等安全断言不受阻塞。
- **初始执行状态**：`NOT_RUN`

### S1-API-05 不可公开资源统一响应且不可枚举

- **用例 ID**：`S1-API-05`
- **名称**：不存在、未发布、下架、撤回、过期和资格未知统一不可用
- **优先级**：P0
- **类型/建议测试层**：安全 + 等价类；接口契约、应用服务集成
- **规则来源**：D-702 §4 `S1-API-05`；D-401 §4、§7；D-602 §5；D-701 §3
- **前置条件**：
  - 为同一资源类型建立不存在、草稿、未发布、已下架、授权撤回、资格过期、资格未知七个独立样本。
  - 各样本使用相同格式的不透明公开 ID，避免测试数据本身泄露状态。
- **测试数据/故障注入**：
  - 每个内部状态写入不同的唯一内部原因哨兵，例如 `S1_API_05_REASON_DRAFT`、`S1_API_05_REASON_REVOKED`。
  - 资格未知样本由资格依赖返回超时或未知结果，不能模拟成明确无资格。
- **步骤**：
  1. 匿名逐一请求七个样本的详情，并以相同请求头重复一轮。
  2. 记录每次 HTTP 状态、公开错误码、公开 message、响应长度类别、响应头和 `requestId`。
  3. 比较各状态对外响应语义，搜索内部状态名、撤回原因、客户信息和原因哨兵。
  4. 请求相邻及随机 ID，确认不能通过差异响应枚举内部资源。
  5. 检查服务端日志可区分内部诊断原因但未把该原因返回公开端。
- **可观察预期**：
  - 七类样本均映射为 `PUBLIC_RESOURCE_UNAVAILABLE`/HTTP 404，公开提示统一为当前不可用语义。
  - 响应不暴露资源是否存在、是否曾发布、授权是否撤回、资格依赖是否超时或任何客户身份。
  - 错误响应使用 `Cache-Control: no-store`；重复请求不会恢复旧内容或产生业务写入。
  - 内部日志可按 `requestId` 诊断真实原因，但字段脱敏且不记录授权证据原件。
- **证据要求**：
  - 七类响应的归一化差异报告、响应头和错误码矩阵。
  - 敏感哨兵扫描结果及公开 ID 枚举尝试记录。
  - 与 `requestId` 对应的脱敏内部诊断记录。
- **阻塞/待决条件**：
  - 公开 `message` 的最终文案和响应外层字段需契约锁定；不得据此锁定页面视觉。
  - 统一不可用码/HTTP、原因不可枚举及资格未知 fail-closed 的安全断言不受阻塞。
- **初始执行状态**：`NOT_RUN`

### S1-API-06 公开 DTO 白名单与内部敏感哨兵

- **用例 ID**：`S1-API-06`
- **名称**：所有公开入口实施字段白名单和数据最小化
- **优先级**：P0
- **类型/建议测试层**：数据安全 + 契约；序列化单元、接口契约、安全回归
- **规则来源**：D-702 §4 `S1-API-06`；D-401 §2、§3.2、§3.3、§6.2、§7、§9；D-602 §2；D-701 §3、§8
- **前置条件**：
  - 首页、品牌、作品列表/详情、业务列表/详情、套餐列表/详情及媒体网关能力均可在隔离环境调用。
  - 测试资源同时具有公开字段和禁止公开的内部字段，媒体网关可观察首个响应及重定向链。
- **测试数据/故障注入**：
  - 在客户姓名、电话、授权证据、授权内部 ID、审核人、内部备注、原始对象 key、供应商桶名、私密 URL、永久签名参数、后台角色、未发布价格中分别写入唯一 `S1_API_06_*_SENTINEL`。
  - 客户端请求附带伪造 `price`、`published`、`authorized`、`visible` 和原始媒体 URL。
- **步骤**：
  1. 调用全部公开 JSON 入口，保存原始响应体与响应头，不只检查反序列化后的客户端对象。
  2. 提取所有字段路径，与评审时的公开 DTO 白名单候选进行对照，并单独扫描所有禁止字段名及哨兵值。
  3. 访问响应中的每个媒体引用，记录 URL 主机、路径参数、响应头和全部重定向目标。
  4. 检查客户端伪造字段是否进入响应或改变发布/资格/价格结果。
  5. 检查相关客户端日志、服务端公开日志和错误响应是否意外记录完整签名 URL或哨兵。
- **可观察预期**：
  - 任何公开响应、响应头、媒体 URL、重定向和客户端可见日志均不出现客户资料、授权证据、内部备注、原始 key、私密媒体、供应商凭证、后台角色、未发布价格或任一敏感哨兵。
  - 媒体只通过 SouthLeaf 受控媒体网关引用提供，不返回或重定向到供应商直链、公共桶或永久签名地址。
  - 服务端只按公开 DTO 显式映射字段，不因内部对象新增字段而自动扩大公开响应。
  - 客户端伪造的发布、授权、价格、可见性及媒体地址不影响结果。
- **证据要求**：
  - 全入口原始响应样本、字段路径清单、白名单/禁止项扫描报告。
  - 哨兵植入清单与零命中结果，媒体 URL/重定向主机检查记录。
  - 序列化层或接口层自动化报告及 `requestId` 对应的脱敏日志。
- **阻塞/待决条件**：
  - **BLOCKED（完整允许字段白名单）**：D-401 的具体 DTO 字段、必填性、枚举和响应外层仍需契约锁定，未锁定前不能以草案字段缺失判兼容失败。
  - 禁止字段、敏感哨兵、受控媒体网关及客户端输入无权改变服务端事实等负向安全断言可立即执行。
- **初始执行状态**：`NOT_RUN`

### S1-API-07 requestId 全链路关联与安全展示

- **用例 ID**：`S1-API-07`
- **名称**：成功、公开错误和内部异常均可通过 requestId 脱敏追踪
- **优先级**：P1
- **类型/建议测试层**：可观测性 + 契约；接口契约、日志集成、页面联调
- **规则来源**：D-702 §4 `S1-API-07`；D-401 §3.2、§7、§9；D-602 §2.1、§6；D-701 §6、§9；P01 §6
- **前置条件**：
  - 能访问脱敏的服务端请求日志，并可按 `requestId` 检索。
  - 准备成功、非法参数、资源不可用、服务不可用和响应转换失败五类可控结果。
- **测试数据/故障注入**：
  - 合法公开资源一个、非法参数一个、不公开资源一个。
  - 对必需依赖注入暂不可用；对 DTO 转换注入格式不匹配，以分别触发 503 与 500。
  - 内部异常文本写入 `S1_API_07_INTERNAL_EXCEPTION_SENTINEL`。
- **步骤**：
  1. 分别触发成功、400、404、503 和 500 结果，记录响应中的 `requestId`。
  2. 校验每个非空 `requestId` 的格式只满足公开标识用途，不包含资源、客户或内部拓扑语义。
  3. 在服务端日志中按每个 `requestId` 检索，核对请求入口、结果类别和诊断事件。
  4. 对其中一个失败请求执行客户端重试，确认新请求获得新的 `requestId`。
  5. 检查公开 message、页面反馈数据和客户端日志，确认内部异常哨兵、堆栈及完整内部 URL 未暴露。
- **可观察预期**：
  - 成功与所有错误响应均携带可关联的 `requestId`；每个请求的标识唯一且能定位对应脱敏日志。
  - 重试生成新的 `requestId`，不把旧标识当作业务幂等凭证。
  - 公开端仅在反馈需要时使用简短标识，不展示堆栈、供应商、内部服务名、签名或异常哨兵。
  - 日志保留诊断所需结果，但不记录客户资料、授权证据原件、原始 key 或完整签名 URL。
- **证据要求**：
  - 五类请求/响应及 `requestId` 映射表。
  - 按标识检索的脱敏日志截取和重试前后标识对照。
  - 客户端展示模型或页面状态记录，证明未暴露内部异常内容。
- **阻塞/待决条件**：
  - `requestId` 最终字段位置、格式、是否向工作室反馈渠道展示仍需联合评审。
  - 标识必须可关联、重试必须生成新标识和敏感信息不得公开不受上述待决项阻塞。
- **初始执行状态**：`NOT_RUN`

### S1-API-08 生产 HTTPS 与小程序合法域名

- **用例 ID**：`S1-API-08`
- **名称**：开发地址与生产 HTTPS/合法域名配置隔离
- **优先级**：P0
- **类型/建议测试层**：配置安全 + 目标环境；构建配置检查、接口联调、微信目标环境/真机
- **规则来源**：D-702 §4 `S1-API-08`、§8；D-401 §3.1、§8、§9；D-602 §10；D-701 §2；P01 §3.5
- **前置条件**：
  - 取得候选生产构建及其实际网络请求观测能力。
  - 取得经评审的环境清单；若正式生产主机或小程序合法域名尚未批准，仅执行不依赖具体主机名的静态安全检查。
- **测试数据/故障注入**：
  - 地址变体：`http://localhost`、`http://127.0.0.1`、明文 HTTP、非批准测试域名、批准域名候选、媒体重定向到非批准域名。
  - 深层链接和媒体请求各准备一个可公开资源。
- **步骤**：
  1. 检查候选生产构建中的 API 基址、媒体网关地址和环境替换结果，搜索 localhost、回环地址及明文 HTTP。
  2. 在目标小程序环境打开首页、列表、详情、分享深链和媒体，记录全部请求主机、协议及重定向链。
  3. 将配置指向明文 HTTP或非批准域名，确认生产构建/发布检查或运行时请求被拒绝且有可诊断错误。
  4. 验证 API 与媒体请求未因重定向离开批准域名范围，也未把开发地址回退为生产兜底。
  5. 记录合法域名平台配置与构建环境标识，核对两者属于同一评审环境。
- **可观察预期**：
  - 候选生产构建不包含或请求 `localhost`、回环地址、明文 HTTP 和未批准主机。
  - 公开 API、受控媒体网关及其重定向只使用 HTTPS 和经批准的小程序合法域名范围。
  - 错误环境配置不会静默回退到开发服务或绕过平台域名校验；失败可通过脱敏日志/`requestId` 诊断。
  - 开发环境可使用的本地地址与生产配置明确隔离，不被本文锁定为生产地址。
- **证据要求**：
  - 候选构建配置扫描结果、环境标识和网络请求清单。
  - 微信目标环境/真机的请求域名、协议、重定向链及平台合法域名配置证据。
  - 非法配置被拒绝的构建或运行记录。
- **阻塞/待决条件**：
  - **BLOCKED（目标环境精确断言）**：正式 API/媒体主机名、小程序合法域名清单和发布环境尚需评审确认。
  - 不阻塞生产必须使用 HTTPS、不得包含 localhost/回环地址、不得访问未批准主机和不得暴露供应商直链的安全断言。
- **初始执行状态**：`NOT_RUN`

## 4. 阻塞条件汇总

1. **API 路径与版本前缀**：D-401 中路径仍为草案；契约锁定前可按能力适配执行安全断言，但不得把草案路径当作生产兼容承诺。
2. **DTO 与响应外层**：具体字段、必填性、可空性和枚举需 D-401/D-602 联合评审；禁止字段与敏感哨兵零泄露不因此延期。
3. **分页与参数边界**：cursor 或 page/size、长度、字符集、默认/最大数量和排序键未定；稳定排序、无重复遗漏、服务端限量和不可注入仍必须验证。
4. **域名与目标环境**：正式 HTTPS 主机和小程序合法域名清单未确认；生产不得使用明文 HTTP、localhost、回环地址、未批准主机或供应商直链属于独立安全门槛。
5. **执行就绪**：需有隔离公开数据源、可控资格结果、受控媒体网关、脱敏日志查询和目标小程序构建。任一缺失只阻塞依赖该设施的执行项，不得填写为通过。

本文件 8 个主用例当前均为 `NOT_RUN`；评审完成和环境就绪后按执行批次逐项记录实际结果、证据与缺陷。
