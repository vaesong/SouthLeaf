## 1. 目的与边界

本文定义阶段一测试使用的环境、隔离标识、可控时间、合成数据配方、故障条件和真实内容核验边界。数据目录描述业务语义和生成规则，不锁定数据库表、最终 API 字段、缓存 TTL、媒体供应商、真机清单或生产发布流程。

合成数据用于证明技术与业务语义；真实内容核验用于确认首批公开品牌、业务、套餐、价格、联系方式、作品资格和客户可见结果。二者必须分别执行和留证，任何合成数据通过都不能替代真实内容确认。

## 4. 隔离规则

1. 每个执行批次使用独立 `runId`；合成品牌、资源公开 ID、内容版本、任务、日志和媒体对象都能回溯该值。
2. 各用例从声明的不可变基线复制数据，不共享可变作品、缓存版本或任务状态。撤回、下架、资格未知、媒体失败和分页测试使用不同资源副本。
3. 并行批次使用不同命名空间、数据分区或等价隔离机制；任何查询都不得读到其他 `runId` 的非基线数据。
4. 公共只读基线必须版本化；需要写入的故障、下架和撤回测试先复制，再改变副本。
5. 缓存键、公开版本、媒体引用和任务幂等标识包含可区分的测试命名空间；验证结束前不得全局清缓存或删除共享数据。
6. 环境变量和密钥由环境安全机制注入，测试数据文件、日志、截图和文档中只保存脱敏引用。
7. 清理只作用于本批次可识别资源，并在证据固化后执行；清理失败登记缺陷或环境事件，不扩大删除范围。
8. 真实内容核验使用单独批次和明确审批，不与合成故障注入并行操作同一公开资源。
9. 禁止在生产执行破坏性故障注入、伪造授权、批量下架或任意清理。需要生产可见核验时，只执行受控、可审计且获批的发布流程。
10. 用例之间存在有意状态延续时，必须在批次选集中声明顺序和共享资源；否则默认完全独立。

## 5. runId 与关联标识

### 5.1 格式

推荐格式：

```text
runId = sl-s1-<UTC日期时间>-<环境短码>-<6位随机串>
示例 = sl-s1-20261009T080000Z-api-a1b2c3
```

随机串只用于避免冲突，不承载客户、设备持有人、电话号码、微信号或密钥。环境短码为 `design/api/h5/wx/device/content`。

### 5.2 传播与记录

- 批次建立时生成 `runId`，一个批次可以包含多个执行记录，但每个可变数据副本必须能追溯到该批次。
- 在接口尚未锁定前，通过测试夹具元数据、公开测试标识、任务标签或等价机制关联；不得为了测试把内部 `runId` 暴露为正式客户字段。
- 每次请求仍使用独立 `requestId`；`runId` 不替代 requestId，也不作为业务幂等键。
- 故障任务另有稳定测试意图标识，用来验证重复执行；其具体字段待实现映射确认。
- 执行记录保存 `runId`、数据基线版本、候选构建、环境实例、时钟点和 requestId 列表。
- 日志检索与清理操作按 `runId` 限定；若实现无法安全关联，相关故障或清理用例标记受阻。

## 6. 可控时钟

阶段一至少需要固定时钟和可步进时钟，以验证发布/资格有效期、排序、版本变化、缓存年龄、任务重试和旧响应。时间统一以带时区的 ISO 8601 记录，测试基准建议写成符号：

| 符号 | 含义 | 使用方式 |
|---|---|---|
| `T0` | 数据基线建立时间 | 所有派生时间的共同起点 |
| `T_publish` | 公开版本生效时间 | 验证生效前后查询 |
| `T_eligibility_end` | 资格有效期边界 | 执行 `−ε / 边界 / +ε`；具体规则来自 A15 |
| `T_withdraw` | 授权撤回事实成立时间 | 观察撤回前后公开结果和任务 |
| `T_cache_expire` | 普通文字投影缓存边界 | TTL 未评审前保持符号，不填具体秒数 |
| `T_retry_n` | 第 n 次允许重试时间 | 退避和最大次数未评审前只记录序列 |
| `T_response_old/new` | 旧请求与新请求返回时间 | 编排乱序，证明旧响应不覆盖新状态 |

规则如下：

- 领域和接口集成优先注入统一测试时钟，不依赖等待真实时间流逝。
- 时间步进必须记录“步进前、动作、步进后”，不得直接改数据库时间绕过业务路径。
- 微信目标环境、真机和真实内容核验若不能使用可控时钟，记录设备时间、服务端时间、时区和误差来源。
- 普通文字缓存 TTL、撤回传播目标、任务超时和性能阈值均待评审；在确认前只测量实际值并留证，不据此判 `PASS` 或 `FAIL`。
- 作品媒体 `no-store`、展示前当前资格复核、资格未知 fail-closed 不是待定 TTL，不得因时钟不可控而放宽。

## 7. 阶段一合成数据配方

配方版本初始记为 `S1-SYNTH-v1-review`。所有显示文本带“测试”标识，图片为团队自制非人物测试图或可证明授权的专用素材，禁止使用客户照片。

### 7.1 品牌与联系方式

| 数据 ID | 内容 | 用途与断言 |
|---|---|---|
| `TD-BRAND-FULL` | 名称“SouthLeaf 测试工作室”；合成简介、工作时间；不可拨打电话标识 `TEST-PHONE-001`；微信标识 `TEST-WECHAT-001`；地址“测试地址（不可导航）” | 首页与关于语义一致；字段来自同一公开事实 |
| `TD-BRAND-PARTIAL` | 仅名称、简介和一种明确测试联系标识；其余字段缺失 | 只展示已确认字段，不用原型值补齐 |
| `TD-BRAND-NO-ADDRESS` | 地址与坐标均缺失 | 不显示历史地址或地图坐标 |
| `TD-BRAND-SENTINEL` | 内部字段带敏感哨兵，公开字段保持普通测试值 | 验证公开 DTO 最小化；哨兵不得出现在响应、页面或媒体 URL |

合成联系标识只验证字段、空态和页面分支，不执行真实拨号或微信联系。系统联系能力必须在 `ENV-DEVICE` 使用经营责任人确认的真实公开联系方式单独核验。

### 7.2 六类摄影业务

| 数据 ID | 业务 | 业务键（测试语义） |
|---|---|---|
| `TD-BIZ-CHILD` | 儿童 | `child-test` |
| `TD-BIZ-FAMILY` | 亲子全家福 | `family-test` |
| `TD-BIZ-WEDDING` | 婚纱 | `wedding-test` |
| `TD-BIZ-PORTRAIT` | 写真 | `portrait-test` |
| `TD-BIZ-MATERNITY` | 孕照 | `maternity-test` |
| `TD-BIZ-IDPHOTO` | 证件照 | `idphoto-test` |

每类生成三个独立资源变体：`已发布且有套餐`、`已发布但无套餐`、`未发布`。四个 `S1-BIZ-*` 主用例对六类逐项执行，共 24 次强制参数化执行；未发布数据只用于服务端拒绝和不返回断言，不由客户端过滤。

### 7.3 套餐与四种价格语义

| 数据 ID | `priceType` 语义 | 合成显示值 | 必须断言 |
|---|---|---|---|
| `TD-PKG-FIXED` | `FIXED` 固定价 | 明确合成金额，如“测试价 1000 元” | 列表/详情语义一致，不被改为起价 |
| `TD-PKG-FROM` | `FROM` 起价 | “测试起价 1000 元起” | 明确显示“起”，不变成固定价 |
| `TD-PKG-INQUIRY` | `INQUIRY` 询价 | “请咨询” | 不返回 0 元或伪造金额 |
| `TD-PKG-UNDISCLOSED` | `UNDISCLOSED` 未披露/未确认 | 不提供金额 | 不返回历史价、活动价或默认定金比例 |

每种语义至少包含已发布列表项和详情；另生成下架副本、旧链接副本、无套餐业务和字段哨兵副本。实际接口字段仍以 D-401 评审结果为准；若名称变化，只更新映射，不改变四种语义断言。

### 7.4 作品、资格与媒体

| 数据 ID | 初始事实 | 预期公开语义 |
|---|---|---|
| `TD-WORK-ELIGIBLE` | 已发布；A15 资格有效；受控媒体绑定和用途有效 | 可由公开查询返回，媒体顺序稳定且每次展示前复核 |
| `TD-WORK-ELIGIBILITY-UNKNOWN` | 已发布；资格读取为未知/超时/无法证明 | fail-closed；首页、列表、详情和媒体均不可公开 |
| `TD-WORK-WITHDRAWN` | 曾合格公开，随后在 `T_withdraw` 撤回 | 首页/列表移除；旧链接和媒体统一安全不可用；失败任务不能恢复公开 |
| `TD-WORK-UNPUBLISHED` | 草稿、未发布或已下架的独立副本 | 公开端不返回，且不可据错误差异枚举内部状态 |
| `TD-WORK-MEDIA-FAIL` | 主资源和资格有效；一个可选媒体读取失败 | 保留可用文字/媒体；失败项可重试且不暴露原始地址 |
| `TD-WORK-INJECTED` | 客户端对象带伪造 `published/authorized/visible` 和媒体地址 | 服务端重查并忽略客户端伪造事实 |

撤回、资格未知与媒体读取失败必须使用独立作品，避免一条失败原因遮蔽另一条断言。媒体使用测试网关引用；配方不假定供应商、桶、缩略图参数或永久 URL。

### 7.5 分页、排序与敏感字段哨兵

分页数据集 `TD-PAGE-STABLE` 至少生成能跨越两页且排序键包含并列值的公开资源，并加入：

- 页边界前后资源、同排序时间不同公开 ID、跨业务资源；
- 一个未发布资源、一个资格未知资源和一个已撤回资源，确保过滤后分页仍无重复、遗漏或越权；
- `DEFAULT_LIMIT`、`MAX_LIMIT`、非法负值、零、超上限和超长 cursor 的符号参数；具体上限未锁定前不填数；
- 同一 cursor 重复请求、版本变化前后请求和非法筛选；
- 受控内容版本，便于区分稳定快照与更新后的新结果。

敏感哨兵数据集 `TD-SENTINEL-PRIVATE` 在仅服务端可见的测试字段中放置唯一、无真实意义的标记：

```text
SENTINEL_CUSTOMER_NAME_<runId>
SENTINEL_CUSTOMER_CONTACT_<runId>
SENTINEL_AUTH_EVIDENCE_<runId>
SENTINEL_INTERNAL_NOTE_<runId>
SENTINEL_STORAGE_KEY_<runId>
SENTINEL_PRIVATE_MEDIA_<runId>
SENTINEL_ROLE_<runId>
SENTINEL_VENDOR_SECRET_<runId>
```

公开响应、响应头、错误、页面状态、媒体 URL、客户端日志和截图中对上述哨兵做负向搜索。哨兵是合成字符串，不得采用真实姓名、手机号、微信号、授权编号、对象 key 或令牌。

### 7.6 网络与依赖故障目录

| 故障 ID | 条件 | 注入位置 | 主要观察 |
|---|---|---|---|
| `FI-NET-OFFLINE` | 无网络/连接失败 | 页面请求前 | 网络提示、主动重试、无假数据回退 |
| `FI-NET-TIMEOUT` | 请求或响应超时 | API/页面边界 | 服务暂不可用、有限重试、旧请求不覆盖新状态 |
| `FI-HTTP-5XX` | 必需依赖或接口 5xx | 查询链路 | 稳定错误、requestId、无内部泄露 |
| `FI-HTTP-RATE` | 限流/明确拒绝 | 依赖适配层 | 不无限重试，保留脱敏原因 |
| `FI-RESPONSE-LOST` | 外部动作完成但响应丢失 | 更新/任务适配层 | 重试不产生重复版本、媒体或审计事件 |
| `FI-RESPONSE-DELAYED` | 旧响应晚于新响应 | 页面请求编排 | 旧响应被忽略 |
| `FI-RESPONSE-MALFORMED` | 缺字段、格式错误、关联 ID 不匹配 | API/依赖响应 | 通用异常或人工处理；不采信错误事实 |
| `FI-ELIGIBILITY-UNKNOWN` | 资格依赖超时/未知 | 公开资格检查 | fail-closed，恢复后可重新核验 |
| `FI-MEDIA-UNREADABLE` | 单项媒体网关读取失败 | 媒体读取 | 主资源按契约降级，原始地址不泄露 |
| `FI-TASK-DUPLICATE` | 同一任务重复/恢复后重放 | 更新/下架任务 | 逻辑结果唯一，允许多次执行日志 |
| `FI-TASK-INTERRUPT` | 本地持久化前后进程中断/重启 | 任务执行器 | 状态可追踪并最终收敛 |
| `FI-CACHE-INVALIDATE` | 缓存失效任务失败 | 撤回/下架后 | 当前查询仍拒绝，不恢复已知不合格内容 |

延迟、带宽、重试次数、退避和超时的具体数值由环境能力及已评审设计提供；当前目录只规定故障语义，不锁定阈值。

## 8. 数据生成、装载与清理

```text
选择配方版本
  → 生成 runId
  → 固定/记录时钟 T0
  → 生成合成事实和唯一哨兵
  → 经正式数据入口或等价测试装载机制建立基线
  → 校验公开与内部观察面
  → 执行用例和故障序列
  → 固化脱敏证据
  → 仅清理本 runId 数据
  → 记录清理结果
```

不得通过直接修改最终汇总状态来伪造合法发布、资格、撤回或下架流程；若为单元层构造状态，必须明确其层级限制。真实内容核验必须使用受控发布/撤回流程，流程尚未确认时相应用例保持受阻。

## 9. 隐私、密钥与证据安全

严格禁止将以下内容放入 Fixture、源码、普通测试库、自动化报告或文档：

- 真实客户姓名、手机号、微信号、地址、订单、预约或家庭关系；
- 真实客户照片、儿童/多人影像、私密成片或授权证据原件；
- 生产 API 密钥、对象存储凭证、签名 URL、Cookie、会话、支付或供应商令牌；
- 生产数据库转储、原始对象 key、内部完整异常和未脱敏日志。

真实内容核验只处理已获准公开的经营资料，并遵守最小可见原则。公开作品资格由授权/隐私责任人确认，测试人员不能补造授权。证据引用确认记录和版本，不复制授权原件；截图或录屏出现设备通知、账号或联系人时先脱敏再归档。

专用测试秘密由环境秘密管理提供，按最小权限和期限配置；泄露时立即停止批次并按安全流程处理，不能把轮换后的旧密钥留作文档证据。
