## 1. 核心定位与设计哲学

本设计方案摒弃冷感暗黑与繁复花哨，确立**「温润奶玉 · 画册流」**为枝南影像小程序的整体前端架构基调：

1. **年轻、温馨、质感轻奢**：契合「两位 95 后女生开的照相馆」的主理人温度。以温润的燕麦暖奶茶色作为整体底色，配合高白瓷大圆角卡片作为内容载体，呈现如高端生活方式沙龙般的柔和触感。
2. **纯粹看作品为主，弱化商业催促**：照相馆的核心资产是打动人心的客照。不设强制催促标签（如剩余席位、状态岛、吸睛大金钮），让客户沉浸于真实温情的照片与故事，被作品打动后在详情页自然发起预约。
3. **字体圆润温馨，杜绝花哨**：主力正文采用清晰、圆润、舒适的现代无衬线体，标题搭配温婉适度的人文宋体，字间距略作舒展，不堆砌大号罗马数字或生硬英文字标。
4. **彻底消除卡片空白，避免审美疲劳**：首页与各子页面拉开视觉节奏，首页采用大片策展杂志流（大封面 + 齐平双联），作品列表默认采用自适应瀑布流，贴紧照片边缘，杜绝卡片下方多余灰白留空。

## 3. 全局组件与布局规范

### 3.1 导航体系：悬浮毛玻璃「灵动水滴胶囊」底栏
- **形态**：放弃传统贴底硬边 TabBar，在页面底部常驻通透的**悬浮毛玻璃水滴胶囊**（高约 56~58px，圆角 28~29px，左右留出 20px 边距）。
- **材质**：`rgba(255, 255, 255, 0.92)` 配合 `backdrop-filter: blur(20px)` 及极细白光边。
- **五个 Tab 项**：首页、作品、服务、关于、我的。
- **指示状态**：选中项加粗加深，并在下方悬浮一抹小巧的焦糖暖棕短线（宽 12px、高 2.5px），轻巧不抢戏。

### 3.2 卡片形态与圆角规范
- **全屏或大型焦点卡**：圆角 `22~24px`；
- **作品与内容次级卡片**：圆角 `16~18px`；
- **分类药丸与操作按键**：圆角 `18~22px`；
- **相框与卡片内图片**：内嵌圆角始终与外框形成和谐同心比例（`12~14px`）。

## 4. 八大核心页面排版细则

### 4.1 【01 首页】大片策展杂志流（有大有小、主次分明、零分层空白）
1. **顶部微标**：干净素雅的「枝南影像 · 记录你生活里柔软的光」品牌签名，不堆砌在线客服或催促状态；
2. **焦点大画轮播**：大幅沉浸式大作卡片（圆角 24px），底部文字融入柔和黑透微暗影；
3. **分类快速滑选**：全部、全家福、个人写真、儿童记录、孕照纪念等圆弧小药丸平滑横滑；
4. **精选摄影故事（杂志大作流）**：
   - **全宽封面大画刊**：单张大片撑起首屏气场，标题与一句话走心描述以微暗影浮于图底；
   - **齐平双联对画**：紧随其后两张并排的等高全景卡，左右尺寸绝对一致、上下严丝合缝齐平，彻底消灭外框分层与底部空白；
5. **工作室寄语温情卡**：底部收尾展现两位 95 后主理人（安娜与方女士）的温暖信条与并排头像。

### 4.2 【02 作品集】自适应瀑布流为主 + 支持一键切等高
1. **页面顶部**：右上角提供小巧温润的 **「▦ 切等高画册 / ☷ 切自适应瀑布」** 切换按键；
2. **默认排版（自适应瀑布流）**：
   - 双列错落展开原生客照比例（横竖原画幅皆可优雅呈现）；
   - 文字紧贴照片底边，有多少行占多高，**彻底消除卡片下方的多余灰白留空**；
3. **切换排版（等高全景画册）**：
   - 统一 4:5 黄金比例，文字浮在微暗影上，左右绝对水平齐平。

### 4.3 【03 拍摄服务】章节画册流
1. **章节式大卡**：每个主题（全家福、个人写真、儿童记录等）以「章节画册」卡片展开；
2. **主视觉呈现**：大号序号（`01`、`02`）+ 主题标题 + 英文副标 + 章节代表作品大图；
3. **套餐行条目**：卡片下方平滑展开所属套餐方案名、简述、起步参考价与「查看方案 ›」指引。

### 4.4 【04 服务详情】三栏数据与透明清单
1. **封面大图**：顶部大圆角沉浸大图与左上角悬浮圆形返回键；
2. **核心三栏规整数据**：在标题下方提供米底规整卡：`参考时长 (分钟)` | `精修底片 (张)` | `专属妆造 (套)`；
3. **精致清单**：服务包含条目与拍摄温馨须知采用小号序号圆钮罗列，条理分明；
4. **静默底栏**：左侧显示参考价，右侧为焦糖黑「预约咨询」实心按键。

### 4.5 【05 作品详情】整页流动大图
1. **封面特写**：全幅大图开场，下方浮出作品标题与系列标签；
2. **多图大画流**：客照完整大图垂直顺序流动（整幅与大特写交替），无多余杂质；
3. **静水深流底栏**：常驻温和卡条（“喜欢这组拍摄风格？安娜全程引导 · 含专属定制妆造” + 「预约同款」）。

### 4.6 【06 关于我们】真实主理人双肖像与官方联系
1. **相馆寄语**：“两位 95 后女生，开了一家风格和审美在线的照相馆……”；
2. **主理人双肖像**：安娜（摄影师）与方女士（化妆师）的高清竖版温润肖像并排呈现，附短小走心介绍；
3. **联系与日常**：电话（一键拨打）、地址（一键复制）、营业时间及微信/小红书官方二维码整洁收纳。

### 4.7 【07 预约咨询】轻松选档期
1. **套餐挑选**：优雅药丸单选项；
2. **横向日历滑轨**：月份与横向星期/日期小卡平滑滑选；
3. **时段微卡**：2x3 时段按钮，已约满时段微弱划线，一目了然；
4. **安全提示**：“提交预约申请后，工作室将在 2 小时内与您微信/电话确认档期，生效前无任何强制扣费”。

### 4.8 【08 我的】温情档案与预约追踪
1. **用户温情卡**：“你好，欢迎来到枝南”，无缝读取微信头像与昵称；
2. **预约状态追踪**：剔除所有“UTC时间”等冷漠技术词汇，以焦糖色胶囊显示`● 预约已确认`，标注到店地址与温馨提醒：“请提前 15 分钟到店，安娜与方女士期待与你们见面”；
3. **快捷服务行**：拍摄需知、在线客服、地址导航有序罗列。
