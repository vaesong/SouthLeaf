# 配置与密钥设计

> 文档编号：D-207
> 文档状态：评审中（阶段一可编码草案）
> 适用范围：阶段一公开查询运行配置；后续密钥仅保留边界
> 更新日期：2026-10-08
> 上游需求：A10、A14-A16
> 上游架构：AT02、AT04、AT09
> 关联计划：P01；对齐 D-401、D-501、D-601、D-602、D-702

## 1. 设计目标

沿用 Java 21 / Spring Boot / MySQL，不要求 Redis 或消息队列；配置支持匿名只读公开查询和内部可追踪补偿。
不交付管理后台、上传工作台、登录、预约、订单、支付或私密交付；缺少后续支付/短信密钥不阻塞阶段一启动。
A15 `delivery` 授权事实、A06 `works` 资格和 A05 `content` 编排不可由环境变量、演示开关或默认授权覆盖。

## 2. 环境配置

候选环境为 `local/test/prod`，分别提供数据库、媒体网关来源、私有对象存储引用、日志级别和任务参数。
生产 API 与媒体网关使用 HTTPS 和明确版本，域名须匹配小程序合法域名；本稿不虚构真实域名、桶名或供应商地域。
`localhost`/模拟存储/示例素材仅限开发测试；生产配置不允许缺项后回退到本地地址、mock 或硬编码历史资料。
公开服务账号的业务事实权限为只读；审计/任务记账与受控维护凭证分离配置，不给匿名查询链路业务改写权限。
配置不替代真实发布/撤回流程：内部审计/任务可写不代表对外增加写 API，受控维护来源仍为上线待确认项。

## 3. 业务配置

运行参数仅管查询上限、超时/重试预算、并发/流大小限制、任务批量/租约/退避和安全缓存行为，不保存经营事实。
品牌名称、地址、电话、微信、六类业务说明、套餐价格和作品素材来自已确认公开版本，不能塞进配置充当事实来源。
没有授权凭证不允许 `defaultAuthorized=true`；不设计跳过资格、开放原图、强行显示旧媒体或关闭撤回检查的开关。
公开投影缓存可配置有界容量/TTL，但每次返回与 304 前都重查当前资格；缓存版本不具有授权含义。
阶段一作品媒体固定经可撤回网关且 `no-store`，原图和衍生图保持非公开；安全不依赖直链到期或缓存失效任务。

## 4. 敏感配置与密钥

秘密包括数据库口令、对象存储访问凭证和必要内部服务凭证；不用仓库、设计文档、小程序包或公开 DTO 传递。
通过部署环境变量或只读受限秘密文件注入；具体秘密托管设施待确认，不要求阶段一新增密钥平台产品。
对象读取凭证只允许读取登记的非公开展示对象；原图维护/上传/删除凭证独立，不向客户端返回签名或存储端点。
`SecretProvider.resolve(secretRef) → 内部 SecretHandle / Unavailable`；句柄不支持日志输出或公开序列化，引用不含秘密值。
轮换保留受控短期过渡、验证新凭证后撤销旧凭证；时限和供应商能力待确认，不用长期共享账号兜底。

## 5. 配置读取、覆盖和生效

`PublicReadConfigLoader.load(environment, configSources) → ValidatedRuntimeConfig / ConfigValidationFailure` 为启动端口。
按默认非敏感配置、环境非敏感配置、部署覆盖形成单一快照；秘密只从受限来源解析，来源优先级不得跨环境混用。
Spring 配置绑定后校验必填、HTTPS/来源白名单、正数预算、上下限、凭证用途和环境；候选键名不锁定最终代码路径。
`PublicReadConfigReader.current() → configVersion + 只读参数`；业务/适配层只读类型化快照，不随请求接受客户端配置覆盖。
阶段一默认通过受控重新部署生效，不提供热更新/配置 CRUD；启动失败不替换当前健康实例，回滚走完整配置校验。

## 6. 阶段配置项

| 候选配置域 | 输入/输出约束 | 缺失或失败处理 |
|---|---|---|
| `public.api` | HTTPS 来源、分页/筛选和请求限制 → 校验后的读取参数 | 生产必需项缺失不就绪 |
| `public.authorization` | A15/A06 读取超时与当前版本核验 → 受限检查策略 | 不允许旧资格兜底；UNKNOWN fail-closed |
| `public.media` | 网关来源、变体白名单、流预算 → 受控读取策略 | 缺少资格/存储能力拒绝对应媒体 |
| `storage.read` | 私有展示对象区域引用和 secretRef → 后端读取句柄 | 校验失败不就绪，不开放桶或原图 |
| `task/audit` | MySQL、领取/租约/退避/保留参数 → 内部运行策略 | 持久化失败可追踪并保持拒绝公开 |
| 阶段二/三 | 身份、预约、支付、交付、网盘与客户通知参数 | 阶段一不加载，不开放对应能力 |

`CheckReadiness(configVersion) → READY/NOT_READY + 内部原因`；公共探针只输出最小状态，具体健康详情受限。

## 7. 配置变更审计

内部审计记录 `changeId/operatorRef/environment/configVersion/changedKeyNames/secretVersionRef/result/time`，不记录秘密前后值。
`AuditConfigChange(ChangeSummary) → auditId / PersistenceFailure`；普通参数摘要亦排除内部存储地址与授权资料。
禁止公开 `/env`、配置 dump 或 Actuator 明细；排障以版本/键名/分类定位，不能输出连接串、签名和客户字段。
发布、轮换和回滚保留责任与验证结果；审计失败不报告受控变更已完成，不能用配置更改授权事实。

## 8. 开发、测试和生产隔离

测试素材和授权状态使用明确标注的测试来源、独立库/桶与凭证；不把“测试通过”当作真实作品授权或生产事实。
生产字段只沿用 D-401：requestId、稳定码、公开 data 和公开版本；媒体 DTO URL 指向网关，不暴露配置/secretRef。
客户端 `media`/`coverMedia` 未二次确认不得显示旧作品媒体，网络失败/后台恢复时隐藏待核验图，不用最近成功缓存兜底。
正式小程序预览/图片缓存行为须真机验证；配置不能许诺远程删除访客已下载副本，第三方缓存不作安全保证。

## 9. 故障与回滚

`ValidateAndStart(environment) → 就绪实例 / 拒绝启动`；生产缺秘密、错误域名、无效预算或 mock 开关一律拒绝就绪。
运行中授权读取/密钥/存储故障拒绝受影响读取；单资源未知为 404、整体服务依赖故障为通用 503，不恢复旧许可。
参数无效为 `PUBLIC_QUERY_INVALID`/400，已合格单图读取失败为 `PUBLIC_MEDIA_UNAVAILABLE`/503，转换失败为 `PUBLIC_RESPONSE_INVALID`/500。
配置错误只在内部分类，对外使用 D-203 通用响应；错误无缓存，无堆栈、秘密或授权原因，不另建公开配置错误码。
回滚只恢复验证过的运行配置，不能回滚授权撤回/下架事实、恢复旧作品投影或改用公共原图；旧秘密已撤销则不能复用。

## 10. 测试和验收

- `S1-API-08`：生产拒绝 localhost/HTTP/mock/缺失域名，测试与生产来源/凭证隔离，公开健康详情不泄密。
- `S1-API-06/07`：秘密不进入 DTO、日志、异常或小程序包；配置审计只保存脱敏键名和版本。
- `S1-WORK-02/03`、`S1-CACHE-02/03/05`：资格读取未知、失效任务失败、旧缓存/304 和配置回滚都不能展示旧作品媒体。
- 验证超时/并发/租约参数非法值、启动失败、轮换失败及恢复路径；阶段外密钥缺失不会启用或阻塞阶段外能力。

## 11. 待确认问题

设计假设：部署时校验并形成不可变配置快照，安全门槛不做可关闭开关；本稿是编码候选，不声称配置或轮换已经部署。
D-602 允许先展示首页/列表缓存与本稿媒体安全规则冲突，D-401 的缓存/媒体到期措辞待同步；交由主代理处理。
真实品牌、联系/价格/作品、授权来源与维护责任仍待确认，运行配置不伪造这些数据，也不预置“已授权”示例。
生产域名、存储供应商/凭证注入轮换、超时/容量/限流/任务参数、审计保留及撤回目标须评审实测后确认。
