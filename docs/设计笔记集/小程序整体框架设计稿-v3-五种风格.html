五大框架核心差异速查（选型指南）

01. 暖玉卡片

• 底色：燕麦奶茶暖底 + 纯白大圆角浮层
• 底栏：悬浮灵动水滴条
• 适用：温馨、亲切、质感像高端独立生活馆，包容性最强。

02. 杂志画报

• 底色：经典暖纸白 + 极细微距线
• 底栏：四等分极简单线栏
• 适用：艺术感最浓郁，像翻阅高定摄影期刊，格调拉满。

03. 东方雅奢

• 底色：宣纸微糙米灰 + 朱砂小印章
• 底栏：汉字经典韵味底栏
• 适用：人文感、书卷气、东方诗性，适合高客单写真与全家福。

04. 光影工坊

• 底色：纯净象牙白 + 无边界大幅通透图
• 底栏：沙龙固定预约操作条
• 适用：类似安缦酒店，极致通透、自信，把照片本身的魅力放大到极限。

05. 灵动岛流

• 底色：柔砂色 + 灵动状态胶囊岛
• 底栏：中心突出珊瑚金预约标
• 适用：95后主理人气质最浓，现代活泼与轻奢兼备，转化率高。
