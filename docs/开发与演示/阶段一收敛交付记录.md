## 复现与冻结

见[演示运行指南](阶段一演示运行指南.md)。仓库根显式配置 SOUTHLEAF_API_ORIGIN 后执行 node tools/verify-source-export.mjs。候选包含正式源码、脚本、工程规范和文档，不含 node_modules、dist、target、unpackage、本机秘密与隔离自动化安装。

最终以 node tools/freeze-stage-one.mjs --write 生成 docs/开发与演示/证据/stage-one-candidate.json，再用 --check 校验；任何受纳入文件增删改都使核验失败。不是 Git 提交或标签，不自动提交用户改动，也不是供应链签名。提交前检查发现 Git 换行规范化会改变原逐字节指纹，已升级清单为 format 2：UTF-8 文本按 LF 规范化计算 SHA-256，二进制按原字节；单独验证换行变换仍通过、实际内容篡改仍拒绝。其他纳入内容变更后仍需复验并重新冻结。
