## 4. 安全审计的准确边界

- OSV 扫描的是实际解析的 Maven compile/runtime 依赖，包含传递依赖，版本与当前 POM 一致；失败/空清单不能算 0。
- 不覆盖构建插件完整供应链、许可证审查、可利用性分析、平台漏洞或未来通告。**不声称完整 SCA 已通过。**
- npm 使用 registry.npmjs.org 的安全接口；镜像接口不实现审计时明确失败。尝试非强制、忽略安装脚本的安全维护更新后，重新 clean install、测试、构建和审计，告警仍为 49；没有 force/peer 覆盖来消除计数。
- 当前官方最新 Vue3 线 vite-plugin-uni 3.0.0-alpha-5030220261016001 仍声明 Vite 5.2.8，且固定 Vue 内部版本。直接安装 npm latest 会落到另一套旧版本/框架，不是安全升级方案。
- 因此不能把“只是开发依赖”“小程序不跑 Vite 服务”当作已修复；对外发布继续阻塞。退出该依赖链需要受支持的升级路线，或经用户确认替换前端技术路线，而不是兼容补丁。
