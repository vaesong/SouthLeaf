1. 真实 Argon2/JDBC 登录、原值空白保全、单会话及原子成功审计。

10. UTC 微秒事件独立提交，外层回滚不撤销事件。

## 4. 验收脚本与安全约束

- V3 迁移、增量授权和探针都在实例清理覆盖内；报告保留主失败/清理失败，不提前写已停止/PASS。
- 新运行使旧 latest PASS/partial 失效；报告原子替换，含 run/source/JAR/probe 绑定。
- 完整构建必须在最终候选 pin 之前；冻结 JAR、主类、库和测试探针，结束检查源/候选不漂移，不在用例之间 install/rebuild。
- 完整入口必须显式提供独立管理 IT 参数，先校验再读取公开凭据；ValidateOnly 仅输入形状，不证明真实身份/TLS。
- 管理-only 驱动单独记录范围和真实报告，不替代原完整入口；不设置 skipTests/skipITs 制造 PASS。此前单独 package 的 -DskipTests 仅避免重复已执行单元层，未计作测试证据。
- 迁移、IT 和默认/生产模式测试的主链保持 VERIFY_IDENTITY；既有安全矩阵独立检查演示兼容、主机名及明文拒绝，不用弱模式替代严格正向链。
