## 1. 本轮目标与进度基线

目标是从已有会话安全内核，推进到隔离测试环境中的可登录后台，再用真实代码跑通媒体发布与预约订单；不是重做阶段一，也不是先堆全部页面。

当前已实现源码包含：安全/会话内核、JDBC 会话及审计、显式迁移、模块与产物隔离、非 Web 管理启动守卫、独立 KDF、C2 JDBC 凭据/认证事件与显式非 Web 登录组合，以及已通过受控隔离 L3/L4 验收的 C3 账号运维 CLI。**C2 已以 owned/disposable fixture 完成 public DB + native regression**，不得把此范围误作原 3306 服务、管理 HTTP、admin-web 或生产验收。S1-D HTTP/admin-web 本地切片已完成并通过专用隔离 L5；S2-A 设计已完成；S2-B–S6 业务实现链仍待后续完成。前期各批的测试数字仅代表相应历史候选，不是当前源树或本轮的复跑。

最初规划批交付限定为计划、设计契约与验收清单。不改 POM/Java/SQL/运行脚本，不建库、不授权、不重启服务。用户随后确认该计划，S1-A 已按 Trellis 完成 PRD/design/implement、上下文校验与任务激活；本轮真实结果见第 8 节，不以文档状态代替测试。

### 3.1 S1-A：模块与产物隔离

- 依据：[D-104](../设计笔记集/01_总体设计/04_阶段二后台运行时模块边界与组合根设计.md)、[D-105](../设计笔记集/01_总体设计/05_阶段二S1模块拆分与构建迁移设计.md)、[ADR-004](../设计笔记集/08_决策记录/ADR-004_阶段二分批交付与后台安全闭环.md)。
- 编码：聚合父 POM；public-api、admin-security-core、admin-security-jdbc、admin-db-policy、admin-runtime、admin-migration-cli；迁移现有源码/资源/测试；适配公开启动、迁移、验证和产物路径。
- admin-runtime 在本批只承接现有 token codec 和拒绝启动的非 Web 入口；无默认 DataSource、无运行 Store、无外部 listener。可编译不等于具备运行能力，S1-B 才实现真实 bootstrap。
- 不加入密码/账号管理、HTTP、业务迁移或新生产配置。保留公开坐标、main class、API 与 Reader 行为。
- 验收：依赖图无环、core 主代码无框架依赖、public jar 无任何 admin 代码/资源、CLI 不进入 runtime、公开链及原有会话事务回归。按 D-105 §9 明确扫描嵌套依赖而非只看源码 import。
- 回退：只逆向恢复本批源/构建/脚本改动，不 reset/clean 工作区，不触碰当前服务；中间产物不得替换运行产物。

### 3.2 S1-B：独立管理运行底座

- 依据：[D-506](../设计笔记集/05_数据与存储/06_后台管理运行隔离与Writer最小权限设计.md)。
- 编码：专属配置选择、独立池、URL/schema/CURRENT_USER/TLS/grants 校验、Verified DataSource 生命周期、同源 Store/事务管理器接线。
- 硬约束：无 Web、无自动迁移、无默认账号、无 public fallback；当前 Writer 精确四表矩阵不扩大。
- 验收分开：配置/解析/架构自动化；独立管理测试 schema 和真实账号的权限正反测试。后一项缺环境标记 BLOCKED，不用 mock 或共库 IT 代替。
- 授权事项：创建/变更隔离测试库与账号需明确授权；准备环境清单可在 S1-A 期间完成。

### 3.3 S1-C：凭据与受控账号生命周期

- 依据：[D-201](../设计笔记集/02_通用后端/01_认证与会话设计.md) §8–12。
- 编码：CredentialVerifier 端口及维护库 KDF adapter、统一失败路径、受控首次初始化/改密/禁用/权限变更命令、安全版本递增、认证事件存储。
- 复用 V2 的 credential_hash，不把密码摘要和会话令牌摘要混为同一算法。新审计事实以新增迁移承载，不改 V2。
- 账号管理工具是独立运维 CLI 和独立身份；Web/runtime 不获得账号写权限。生产角色仍受 Q06 门禁，测试权限显式提供。
- 验收：无默认密码；初始化重复/并发拒绝；改密/禁用与签发竞争；成功事实和审计同事务；凭据/原 token 不进入日志；原四表权限的扩展有精确迁移与负向验证。
- 本批仍不开 HTTP。KDF 实际依赖版本、参数负载基准、账号 CLI 恢复权限和新增迁移字段在该批编码前再次核实，不把本文当作 SQL 已锁定。

### 3.4 S1-D：HTTP 安全与最小后台

- 依据：[D-403](../设计笔记集/04_接口与外部契约/03_后台管理接口.md)、[D-606](../设计笔记集/06_客户端/管理后台/01_工作台与待办.md)。

- 验收：HTTPS 浏览器 → 真实管理 API → 隔离 MySQL 全链；登录、退出、禁用/改密后失效；CSRF/CORS/越权/故障负向测试；公开小程序回归。
