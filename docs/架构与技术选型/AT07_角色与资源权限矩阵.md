# SouthLeaf 角色与资源权限矩阵

> 文档编号：AT07  
> 文档类型：权限与资源边界前置设计  
> 文档状态：基于 AT04、AT05、AT06 的设计稿  
> 更新日期：2026-10-06  
> 前置文档：[AT04_总体架构设计草案](AT04_总体架构设计草案.md)、[AT05_高风险业务决策矩阵](AT05_高风险业务决策矩阵.md)、[AT06_状态转换矩阵](AT06_状态转换矩阵.md)

## 1. 文档目的

本文件明确 SouthLeaf 各类身份对业务资源的访问和操作边界，作为后台菜单、接口授权、数据查询范围、审计和详细 API 设计的共同输入。

权限判断不能只看角色。统一采用：

```text
角色 + 操作 + 资源归属 + 当前业务状态 + 敏感数据范围
```

SouthLeaf 是单工作室系统，不设计多工作室租户隔离；但仍需区分客户身份、工作室工作人员、系统任务、支付回调和对象存储访问。

## 2. 身份类型

| 身份 | 说明 | 是否可登录后台 |
|---|---|---:|
| 客户 | 预约联系人或被明确授权的交付访问人 | 否，使用客户侧身份入口 |
| 工作室负责人 | 单工作室经营负责人，拥有高风险经营操作权限 | 是 |
| 管理员 | 负责日常内容、预约、订单和履约操作 | 是 |
| 摄影师 | 可选的履约协作人员，只访问被分配资源 | 是，受限后台 |
| 支付回调身份 | 微信支付等外部平台回调，不是人工用户 | 否 |
| 系统任务身份 | 失效、查单、通知、交付清理等后台任务 | 否 |
| 对象存储服务身份 | 文件上传和签名地址服务身份，不直接代表业务授权 | 否 |

## 3. 资源分类

| 资源 | 典型敏感性 | 归属判断 |
|---|---|---|
| 公开品牌内容 | 低至中 | 发布状态与公开授权 |
| 公开作品/案例 | 中至高 | 作品授权、资产授权和发布状态 |
| 客户档案 | 高 | 客户身份或工作室业务关系 |
| 预约与档期 | 中至高 | 客户订单归属或工作室管理范围 |
| 订单与套餐快照 | 高 | 客户订单归属或工作室管理范围 |
| 支付与退款事实 | 极高 | 客户订单归属、财务角色和业务状态 |
| 履约记录 | 高 | 客户订单归属或摄影师分配范围 |
| 私密成片 | 极高 | 交付授权、订单归属、支付和发布状态 |
| 审计记录 | 极高 | 仅负责人、审计授权和系统内部 |
| 系统配置与密钥 | 极高 | 负责人或受限运维角色 |

## 4. 客户权限

### 4.1 内容与公开信息

| 操作 | 权限 | 条件 |
|---|---|---|
| 查看首页、工作室信息、业务分类、套餐 | 允许 | 内容处于公开发布状态 |
| 查看公开作品和案例 | 允许 | 作品已发布且公开授权有效 |
| 提交预约申请 | 允许 | 填写必要字段，选择可提交的日期和固定时段；申请不占硬档期 |
| 查询公开可选时段 | 允许 | 仅显示可提交状态，不承诺最终成功 |

### 4.2 自己的业务资源

| 操作 | 权限 | 条件 |
|---|---|---|
| 查看自己的预约 | 允许 | 只能访问本人作为联系人或被授权的预约 |
| 取消自己的预约 | 允许 | 当前状态允许；退款规则由系统和工作室审核决定 |
| 申请改期 | 允许 | 通过协商流程提交；不能自行覆盖原日期 |
| 查看自己的订单 | 允许 | 仅限订单归属或显式授权范围 |
| 在线支付定金/尾款 | 允许 | 对应分期处于待支付，支付金额必须固定匹配 |
| 查看支付结果 | 允许 | 只能看到本人订单和安全的支付摘要，不返回敏感渠道数据 |
| 申请问题处理或退款 | 允许 | 形成申请，不直接改变支付事实或退款结果 |
| 查看履约进度 | 允许 | 仅本人订单的对外状态投影 |
| 查看成片 | 允许 | 身份验证、订单归属、交付已发布、尾款已付清、授权有效且小程序入口未到期 |
| 下载成片 | 允许 | 同上；服务端生成短期访问地址，不暴露永久对象地址 |
| 邀请或添加家庭成员 | 首版不直接允许 | 由后台显式添加，后续再评估客户侧邀请流程 |

### 4.3 客户禁止操作

客户不能：

- 确认预约或创建订单；
- 占用、释放或封锁档期；
- 修改套餐、价格或服务内容快照；
- 标记定金、尾款或线下收款已支付；
- 确认拍摄完成、触发尾款或发布交付；
- 授予公开案例授权；客户授权应通过明确同意流程形成事实；
- 访问其他客户、后台审计、原始对象地址或系统配置。

## 5. 工作室负责人权限

负责人是高风险操作的最终审批角色，权限应有明确审计，不应以“万能管理员”替代所有业务边界。

| 资源/操作 | 负责人 |
|---|---|
| 品牌内容、公开作品和套餐发布/下架 | 允许 |
| 套餐版本、价格、定金配置维护 | 允许；不回写既有订单快照 |
| 时间段配置、后台封档/解封 | 允许；不得静默覆盖已确认占用 |
| 线上/线下预约确认、拒绝、取消和改期审核 | 允许 |
| 确认预约并自动生成订单 | 允许；必须幂等和审计 |
| 订单修订、改期、异常处理 | 允许；原快照不可覆盖 |
| 线下收款登记与复核 | 允许 |
| 退款审核、退款金额确认和人工处理 | 允许；必须保留原因和审计 |
| 确认拍摄完成、触发尾款 | 允许 |
| 补拍、缺席、服务异常处理 | 允许 |
| 私密成片上传、校验、发布、撤回 | 允许 |
| 成片授权给预约联系人或家庭成员 | 允许；显式记录授权范围和有效期 |
| 公开案例授权记录、发布与撤回 | 允许；必须有客户明确同意 |
| 过期交付通过网盘人工补充 | 允许；记录接收人、范围、时间和链接有效期 |
| 查看客户敏感资料和完整审计 | 允许，遵守最小必要原则 |
| 修改系统密钥和基础运维配置 | 仅在受限运维流程中允许，不通过普通业务界面直接操作 |

## 6. 管理员权限

管理员负责日常运营，但默认不拥有不可逆或高风险财务与授权权限。

| 资源/操作 | 管理员 |
|---|---|
| 内容草稿、作品和套餐日常维护 | 允许；发布权限按工作室配置 |
| 时间段查询和一般封档申请 | 允许；高风险封档可要求负责人确认 |
| 预约查看、联系客户、拒绝和确认 | 允许；确认并成单必须审计 |
| 预约取消和改期 | 允许；退款影响部分需负责人审核 |
| 订单查看和履约安排 | 允许 |
| 订单快照或价格直接修改 | 禁止；只能发起修订流程 |
| 线下收款登记 | 允许录入，是否核验由负责人或双人复核规则决定 |
| 退款申请 | 允许发起 |
| 退款审核和金额最终确认 | 默认禁止，由负责人审核 |
| 确认拍摄完成、触发尾款 | 允许 |
| 记录缺席、取消、补拍和异常事件 | 允许 |
| 成片上传和校验 | 允许 |
| 成片发布、撤回和客户授权变更 | 默认需负责人确认 |
| 查看私密成片 | 仅限处理业务所需范围，全部访问审计 |
| 查看完整支付凭证和审计 | 按最小必要授权；敏感字段脱敏 |

## 7. 摄影师权限

摄影师不是财务或内容发布角色。首版可以不启用独立摄影师账号，但模型预留该边界。

| 资源/操作 | 摄影师 |
|---|---|
| 查看被分配的预约和拍摄安排 | 允许 |
| 查看完成拍摄所需的最小客户信息 | 允许，敏感字段最小化和脱敏 |
| 修改套餐、价格、订单快照 | 禁止 |
| 确认预约、占用或释放档期 | 禁止 |
| 登记拍摄备注或履约事件 | 允许，不能直接触发尾款 |
| 确认拍摄完成 | 首版禁止，由负责人或管理员操作 |
| 上传被分配订单的成片 | 可允许，文件进入校验流程，不自动发布 |
| 发布、撤回或删除成片 | 禁止 |
| 访问其他订单或客户 | 禁止 |
| 发起或审核退款、登记收款 | 禁止 |

## 8. 非人工身份权限

### 8.1 支付回调

支付回调只允许：

- 验证外部签名和通知来源；
- 根据外部支付单、订单和分期幂等落库；
- 推进支付尝试和支付分期状态；
- 触发必要的订单摘要更新和后续任务。

支付回调不能：

- 修改套餐、价格或订单快照；
- 直接确认预约或占用档期；
- 直接发布或访问成片；
- 绕过退款审批或角色权限。

### 8.2 系统任务

系统任务只允许执行被明确授予的任务范围，例如：

- 待确认申请超时失效；
- 定金期限复核、订单失效和档期释放；
- 支付查单和退款重试；
- 通知发送和失败重试；
- 交付入口到期下架；
- 孤立对象清理和数据一致性检查。

每次任务执行必须使用任务幂等键、记录执行结果和失败原因，不得以系统任务身份绕过业务审计。

### 8.3 对象存储

对象存储服务身份只提供上传、下载或短期签名地址能力。它不判断：

- 客户是否属于订单；
- 尾款是否付清；
- 交付是否已发布；
- 公开授权是否有效。

上述判断必须由应用服务先完成，再按最小权限向对象存储申请短期访问能力。

## 9. 高风险操作清单

以下操作必须有强权限、幂等、审计和明确错误处理：

- 确认预约并创建订单；
- 后台创建线下预约和占档；
- 改期、取消和释放档期；
- 修改或延长定金截止时间；
- 登记、核验或冲正线下收款；
- 退款审核、退款发起和人工补偿；
- 确认拍摄完成并触发尾款；
- 发布、撤回和授权私密成片；
- 记录公开案例明确授权和撤回；
- 通过网盘补充交付已下架文件；
- 查看客户敏感资料、支付凭证和完整审计。

## 10. 权限设计待补充

- 客户身份认证方式、联系人变更和家庭成员身份验证；
- 负责人和管理员的双人复核是否用于退款、线下收款和公开发布；
- 摄影师账号是否在首版启用以及具体分配规则；
- 敏感字段分级、脱敏字段清单和审计保留期限；
- 错误码、接口级权限声明和后台菜单映射。

## 11. 下一步

权限矩阵已作为第 5 步配套基线。第 6 步按模块补充身份绑定、后台操作流程、摄影师账号启用范围、敏感字段和页面级验收；完成后再映射到接口级权限声明和后台菜单。
