## 1. 专题目的

本专题分析工作室如何在拍摄完成后整理、校验、发布和交付精修图片与原片，以及如何管理客户私密访问授权和公开案例授权。

“交付”不是简单上传文件；“授权”也不是一个笼统的同意勾选。客户私密交付、公开案例展示、工作人员处理文件和工作室保存原件是不同目的、不同对象和不同访问条件，必须分别判断和记录。

本文件回答：

- 首版交付什么文件，如何组织交付批次；
- 工作室如何上传、校验、准备和发布成片；
- 尾款、订单归属、授权和入口期限如何共同决定客户能否访问；
- 预约联系人、拍摄人和其他家庭成员分别有什么访问资格；
- 客户如何在小程序中预览和下载原片/精修图；
- 交付入口到期、撤回、网盘补交和原文件保管如何区分；
- 客户公开案例授权如何取得、限定范围、证明、撤回和执行；
- 公开案例与私密交付图片如何分离；
- 负责人、管理员、摄影师、客户和对象存储身份分别能做什么；
- 交付和授权异常如何反馈、重试、审计和验收。

本专题不定义数据库表、API 字段、对象存储厂商、签名算法、图片处理实现、病毒扫描方案、保留期、下载地址格式或页面组件。文件、交付、权限、事务、错误码等技术前置约束引用 AT05-AT09；A15 负责交付和授权的业务事实、任务、用户反馈与验收。

A15 的核心判断是：

```text
上传成功 ≠ 文件已校验
文件已校验 ≠ 交付已发布
尾款付清 ≠ 自动拥有成片访问权
私密交付授权 ≠ 公开案例授权
公开案例必须取得客户明确同意，默认不公开
预约联系人默认拥有私密交付访问资格，其他家庭成员需后台显式添加
小程序入口到期只关闭小程序访问，不代表工作室删除原文件
公开授权撤回、私密访问撤回、入口到期、网盘补交和物理删除是不同事件
```

## 2. 专题边界与规则归属

### 2.1 A15 拥有的需求

A15 负责以下成片交付与授权需求：

- 首版精修图片和原片的交付范围；
- 订单、拍摄履约和交付批次之间的业务关系；
- 文件上传、校验、准备、发布、撤回、到期和归档的用户可见生命周期；
- 交付批次的客户访问开放期和实际截止时间；
- 尾款结清后仍需满足的交付发布、身份归属和授权条件；
- 带水印预览和正式下载不加水印的访问差异；
- 预约联系人和其他被授权人员的私密交付资格；
- 家庭成员由后台显式添加、授权范围与撤回；
- 公开案例授权主体、范围、用途、渠道、有效期、证据和撤回事实；
- 公开案例授权与私密交付授权的分离；
- 案例授权结果提供给 A06，由 A06 计算案例公开资格和隐藏行为；
- 交付入口到期后的人工网盘补充交付记录；
- 原文件保管、客户访问、公开媒体撤回和物理删除的概念分离；
- 负责人、管理员、摄影师和系统身份对文件、授权和交付的操作边界；
- 访问审计、下载审计、通知、异常、人工补偿和验收标准。

### 2.3 公开授权事实和案例公开资格

历史文档中公开授权同时出现在 A06 和 A15。为避免重复维护同一事实，职责明确如下：

- **A15 持有公开授权事实**：授权主体、对象范围、用途、渠道、有效期、证据、撤回和执行记录；
- **A06 消费授权结果**：决定案例、图片、首页引用、作品列表和相关作品当前是否公开；
- **A05 管理首页编排**：只引用已经满足公开资格的案例；
- **A11 管理身份关系**：确定授权人、拍摄人、参与人、家庭成员和监护关系。

A15 不能替 A06 定义案例如何展示或分类；A06 不能再创建第二套授权同意和撤回主记录。

### 2.4 A15 的唯一主规则

交付、私密授权与公开授权必须保持以下关系：

```text
客户支付尾款 ≠ 客户自动同意公开
客户收到成片 ≠ 成片可进入公开案例
同意私密交付 ≠ 同意公开展示
授权预约联系人访问 ≠ 授权所有拍摄人或家庭成员
单图公开授权 ≠ 整个案例和所有照片均可公开
公开授权撤回 ≠ 删除客户私密交付文件
小程序入口到期 ≠ 原文件删除
网盘补充交付 ≠ 恢复小程序入口
对象存储地址 ≠ 业务访问授权
```

访问决策必须根据具体身份、订单归属、交付发布状态、尾款支付事实、私密授权、入口有效期和访问用途共同判断；公开展示则依据客户明确同意和授权范围判断，不依赖订单支付或私密交付状态。

## 3. 已确认规则与证据口径

### 3.1 已确认交付和授权规则

以下规则来自 A04、A06、A11、A13、A14 和 AT05-AT09，作为 A15 业务基线：

- 首版交付精修图片和原片，暂不纳入视频与压缩包；
- 交付逻辑上区分不同文件类型或交付分组；
- 文件需要绑定订单、交付批次和文件类型；
- 上传成功不代表文件校验完成或可以发布；
- 只有经过校验的文件才能进入客户交付发布；
- 尾款付清前不开放任何成片预览和下载；
- 客户访问还需要身份验证、订单归属、交付已发布、授权有效和入口未到期；
- 小程序内预览使用带水印版本；
- 正式精修图和原片下载不加水印，首版不限次数；
- 访问和下载均需要审计；
- 预约联系人默认拥有私密交付访问资格；
- 其他家庭成员需由后台显式添加并记录授权范围和有效期；
- 首版不默认生成公开分享链接或允许客户自由添加家庭成员；
- 小程序交付入口默认开放 1 周，支持后台配置；
- 每个交付批次保存实际截止时间，修改默认期限不回写历史批次；
- 小程序入口到期只关闭客户侧访问，不自动删除工作室原文件；
- 客户确有需要时，工作室可以人工通过网盘等方式补充交付；每次链接有效期由工作室设置；
- 网盘补充交付需要记录接收人、交付范围、有效期、操作者和原因，并受权限控制；
- 公开案例必须取得客户明确同意，默认不公开；
- 公开授权与私密交付授权分开记录；
- 公开授权按对象范围、用途、渠道和有效期管理；
- 客户撤回公开授权后停止后续公开展示并保留撤回审计；
- 公开授权撤回不自动删除客户私密交付文件；
- 对象存储只提供存储和技术访问能力，业务授权由应用判断；
- 原文件保管期、备份、恢复和物理删除规则尚未确认，不因入口到期默认删除。

### 3.2 证据口径

| 标记 | 含义 |
|---|---|
| 已确认需求 | 用户讨论、A04/A06/A11-A14 或 AT05-AT09 已明确的交付和授权约束 |
| 原型证据 | 当前代码、页面、资源或构建产物中的相关线索，只证明历史原型表达过该方向 |
| 产品建议 | 为形成可运营交付与授权体验提出的方案，仍需工作室实际验证 |
| 待验证行为 | 尚无真实上传、交付、撤回和授权记录支持的判断 |
| 待确认经营内容 | 文件保管策略、授权凭证方式、家庭授权审核和异常操作流程 |

当前工程没有正式私密相册、交付批次、文件上传、访问权限、公开授权或撤回记录。套餐页的“精修张数”“原片数量”“相册”等文案属于历史原型，不能直接证明当前套餐承诺或交付文件已经准备好。

## 4. 当前工程证据与问题

### 4.1 “我的相册”仅为占位入口

当前 `frontend/pages/my/my.vue` 存在“我的相册”入口，但点击后显示“开发中，敬请期待”。当前没有可验证的：

- 客户私密交付列表和详情；
- 订单与交付批次关联；
- 精修图、原片分组；
- 尾款门槛；
- 交付发布状态和到期时间；
- 预约联系人或家庭成员授权；
- 带水印预览和无水印正式下载；
- 访问/下载审计；
- 入口到期、撤回或网盘补充交付。

### 4.2 公开作品是静态原型

当前作品、首页和详情页通过前端数组与静态资源展示作品图片，构建产物也包含相关打包内容。工程没有正式案例媒体、对象授权、作品发布状态或图片撤回能力。

这些静态作品不能证明其客户授权仍然有效，也不能证明它们等同于正式私密交付文件。A06 已要求缺少明确授权的客户照片默认不可公开；A15 负责授权事实和访问边界。

### 4.3 后端没有文件和交付业务能力

当前后端检索到本地固定目录图片扫描工具和轮播原型，没有正式对象存储服务、上传会话、交付批次、文件校验、客户下载、签名访问、公开授权或访问审计能力。

本机文件路径或轮播目录不是私密成片的正式存储和授权机制。对象存在也不能推导文件属于某客户、订单已付尾款或交付已经发布。

### 4.4 当前问题结论

| 问题 | 当前表现 | 交付/授权风险 |
|---|---|---|
| 没有交付批次 | “我的相册”是占位 | 无法区分待准备、已发布和到期 |
| 没有文件校验 | 无业务文件登记和完整性校验 | 文件缺失、损坏或类型错误仍可能被分享 |
| 没有支付门槛 | 交付和尾款未关联 | 未付尾款可能被错误开放文件 |
| 没有身份授权 | 无订单归属和访问权限 | 他人可能访问客户私密成片 |
| 公开/私密未分域 | 静态作品与客户相册概念不清 | 私密文件可能误作为公开作品展示 |
| 没有明确同意 | 无公开授权事实、范围和证据 | 未授权照片可能持续公开 |
| 没有撤回能力 | 无案例或图片级隐藏链路 | 撤回后公开入口无法统一停止 |
| 没有期限管理 | 无交付开放截止时间 | 客户入口永久有效或突然失效 |
| 无文件保管策略 | 无备份、恢复和删除规则 | 到期行为可能误删工作室原件 |
| 无访问审计 | 无预览、下载和网盘记录 | 无法追溯谁访问或补交文件 |

## 5. 角色与访问关系

### 5.1 预约联系人

预约联系人默认是该订单私密交付访问授权对象。其访问仍需满足：

- 身份有效；
- 订单归属或明确授权关系匹配；
- 交付已发布；
- 尾款已付清；
- 私密交付授权仍有效；
- 小程序入口未到期；
- 文件状态允许当前访问用途。

预约联系人可以不是实际拍摄人。预约联系人默认交付资格不等于其自动代表所有拍摄人同意公开案例，公开同意应按授权主体、拍摄参与人和适用范围独立判断。

### 5.2 实际拍摄人和参与人

实际拍摄人、儿童、家庭成员、婚纱双方或其他参与人可能出现在成片中，但不会因参与拍摄自动获得：

- 订单详情和付款信息访问权；
- 成片下载权；
- 公开案例发布权；
- 代替其他参与人同意公开的权利。

儿童、多人合影和其他敏感影像涉及的授权主体、监护关系和多人意见冲突处理，需要工作室明确核验规则。未能确认授权范围时默认不公开。

### 5.3 被授权家庭成员

首版家庭成员访问由后台显式添加，不允许客户凭相同手机号、家庭关系或分享链接自动获得权限。后台授权至少明确：

- 被授权的身份；
- 对应订单和交付批次；
- 授权范围，例如预览、下载或两者；
- 授权开始和截止时间；
- 授权发起人和审核人；
- 撤回状态和撤回时间。

被授权家庭成员只获得明确范围内的文件访问权，不因此获得订单修改、退款、预约改期或支付管理权限。

### 5.4 工作室负责人

负责人可以：

- 管理订单交付准备、文件校验和发布；
- 授予、修改或撤回私密交付访问授权；
- 记录公开案例授权证据、范围和有效期；
- 处理公开授权撤回及跨端下架；
- 审核网盘补充交付；
- 查看完整访问和下载审计；
- 决定工作室原文件保管和删除操作，但须遵循后续明确的保管策略。

### 5.5 管理员

管理员可以按授权：

- 上传和校验成片；
- 整理交付批次和待发布内容；
- 联系客户确认交付准备；
- 发起发布、撤回或客户授权变更；
- 提交网盘补交申请；
- 查看完成日常工作所需的访问和任务状态。

管理员默认不能绕过尾款、文件校验或明确授权发布；高敏感授权和网盘补交默认由负责人确认，具体复核层级需工作室验证。

### 5.6 摄影师

摄影师可以在被分配范围内：

- 上传候选成片或交付素材；
- 查看文件上传和校验状态；
- 提交修图、重传或异常建议。

摄影师不能：

- 直接发布客户交付；
- 决定客户是否有权访问；
- 给家庭成员授权；
- 记录或修改客户公开同意事实；
- 将私密成片直接变成公开案例；
- 删除工作室原文件或绕过文件保管规则。

### 5.7 对象存储和外部网盘

对象存储身份提供文件保存、上传和技术访问能力，不判断客户身份、订单归属、尾款、发布状态或授权。应用服务先完成业务授权，再请求短期访问能力。

网盘是工作室人工补充交付的外部渠道。网盘链接不是长期业务授权；每次补交都需要明确接收人、范围、有效期、操作人和撤回/失效记录。

## 6. 交付内容和批次

### 6.1 首版交付内容

首版支持：

- 精修图片；
- 原片。

首版暂不纳入视频和压缩包。精修图与原片需要在客户和后台能够区分的分组或文件类型中呈现，但本专题不锁定最终技术对象结构。

套餐页面历史文案中的照片数量、产品数量、实体相册和交付时限必须由 A07/工作室确认后进入订单快照；不能从原型文案自动生成交付数量或发布日期。

### 6.2 交付批次

交付任务与订单关联，工作室可以按一次或多次整理文件。首版可以采用单批次运营，但要能表达：

- 属于哪个订单；
- 交付哪些类型的文件；
- 当前上传、校验、待发布、已发布、撤回或到期状态；
- 哪些客户身份可以访问；
- 实际发布和访问截止时间；
- 文件异常和重试结果；
- 与尾款、授权和服务异常的关系。

是否允许同一订单分阶段发布多批成片、是否支持选片和后续相册设计，需工作室进一步确认。首版不应因此假设所有交付只有一个批次或全部一次到齐。

### 6.3 交付状态基线

A15 使用 AT06 的交付状态基线：

| 状态 | 含义 | 客户可访问 |
|---|---|---:|
| 未准备 | 尚未进入文件整理/交付准备 | 否 |
| 上传中 | 文件正在上传或登记 | 否 |
| 校验中 | 文件类型、完整性或必要元数据检查中 | 否 |
| 已准备 | 文件已校验但尚未发布 | 否 |
| 已发布 | 满足支付、授权和发布条件，交付入口开放 | 是，仍需逐次权限判断 |
| 入口已到期 | 小程序客户入口截止 | 否，通过人工补交另行处理 |
| 已撤回 | 客户侧访问因业务原因被停止 | 否 |
| 已归档 | 工作室保留业务记录/原文件，不代表客户可访问 | 否，除非另有授权途径 |

交付状态不等同于订单完成、支付状态或文件物理存储状态。

## 7. 文件上传、校验和发布

### 7.1 上传准备

后台进入订单交付任务时，需要确认：

- 订单和拍摄履约确实存在；
- 当前上传人有该订单文件操作权限；
- 文件类型属于已确认交付范围；
- 客户隐私、人物授权和文件用途明确；
- 当前批次和交付范围与订单服务约定一致；
- 是否涉及补拍、质量争议或退款/售后处理中。

上传素材不能因为文件名、目录或工作人员口头说明就自动归属某一客户订单。

### 7.2 文件登记和校验

每个文件或文件组需要能够关联订单、交付批次、文件用途和处理状态。发布前至少校验：

- 上传过程完成且文件可读取；
- 文件类型、大小、数量或交付范围符合配置；
- 必要的完整性/元数据检查已完成；
- 文件关联到正确订单和批次；
- 文件不是公开案例版本误传到私密交付，或私密文件误传到公开媒体；
- 如有水印预览版本，预览和正式下载用途区分清楚；
- 不包含不应交付的测试图、临时稿、内部备注或其他客户文件。

校验未完成或失败时，文件不得发布。上传成功但对象缺失、内容损坏或元数据不匹配时进入待重传/人工处理。

### 7.3 发布前提

交付批次发布前需要同时检查：

- 订单和批次关联有效；
- 拍摄履约进入允许交付的状态；
- 尾款已由服务端支付事实确认结清；
- 发布批次内全部文件已通过校验；
- 私密交付授权对象和范围明确；
- 访问开放期和实际截止时间已确定；
- 不存在阻止发布的服务异常、撤回或隐私争议；
- 发布操作人有相应权限；
- 客户将获得的交付说明和通知内容准确。

尾款支付成功只满足支付门槛，不自动把文件发布给客户。工作室仍需完成文件整理、校验、授权检查和显式发布。

### 7.4 发布和撤回

发布成功后：

- 客户可以在满足全部授权条件时访问；
- 批次保存真实发布时刻和实际入口截止时间；
- 客户收到交付已发布和访问期限通知；
- 后台能够查看发布人、校验结果、文件组和访问状态。

撤回后：

- 停止客户小程序访问和后续短期访问地址发放；
- 说明撤回范围和客户安全可见结果；
- 记录撤回操作者、原因、时间和影响范围；
- 保留文件和历史访问审计；
- 不自动物理删除工作室原文件；
- 如撤回源于授权撤销、文件错误或服务异常，按对应业务事实处理。

## 8. 客户私密交付访问规则

### 8.1 访问条件

客户预览或下载每次都需满足：

```text
身份有效
+ 订单归属或显式授权关系匹配
+ 交付批次已发布
+ 尾款支付事实已结清
+ 私密访问授权有效
+ 小程序入口未到期
+ 文件处于可访问状态
+ 当前访问用途符合授权范围
```

只有同时满足条件，服务端才能提供带水印预览或正式下载。客户端传入订单号、文件号、家庭关系或对象路径不能替代授权判断。

### 8.2 预览与正式下载

尾款付清、交付已发布、身份和授权有效且入口未到期后：

- 小程序内预览使用带水印版本；
- 正式精修图和原片下载不加水印；
- 首版不限正式下载次数；
- 每次访问和下载均记录审计；
- 不向客户端暴露永久对象地址；
- 预览失败、下载中断和链接过期可安全重试；
- 重试或再次访问不会绕过新的撤回、到期或授权状态。

### 8.3 无权访问和授权撤回

客户无权访问时，提示应明确当前不能查看并提供下一步，例如确认身份、联系预约联系人或联系工作室；不要泄露该订单是否存在、其他客户身份或内部授权原因。

私密访问授权撤回后：

- 被撤回身份后续不能查看或下载对应范围；
- 其他仍有效的被授权身份不一定同时失效；
- 已发放的短期访问地址应尽可能停止后续使用，并在有效期内缩短暴露窗口；
- 记录撤回人、时间、范围和原因；
- 不因此撤回客户公开案例授权，除非明确同时发生该项授权撤回。

### 8.4 家庭成员授权

首版不允许客户自行创建分享链接或任意添加家庭成员。工作室后台显式授权时需要核实接收人身份和客户意图，并明确权限范围与期限。

家庭成员授权不自动授予：

- 订单修改权；
- 改期/取消权；
- 退款申请之外的财务操作权；
- 公开案例同意权；
- 对其他家庭成员影像的再次分享权。

授权主体能否代替儿童或其他参与人作出公开同意，必须按身份和业务规则另行确认，不能由私密交付访问关系自动推导。

## 9. 交付期限、到期与原文件保管

### 9.1 小程序入口期限

小程序交付入口默认开放 1 周，支持后台配置。每个批次需要保存自身实际截止时间：

- 后续修改默认配置只影响新发布批次；
- 已发布批次继续按创建时保存的截止时间执行；
- 到期前按配置提醒预约联系人；
- 到期后停止小程序交付入口和下载授权；
- 客户看到入口已到期和联系工作室的路径；
- 后台能够查看到期批次并发起人工补交。

到期是客户侧访问资格变化，不是订单完成、文件归档或物理删除的同义词。

### 9.2 网盘人工补充交付

入口到期后，客户确有需要时，工作室可以通过网盘或其他人工渠道补充交付。每次补交需要：

- 核实接收人身份和订单归属；
- 明确文件或交付范围；
- 设置本次链接有效期；
- 记录链接创建/发送人、时间、原因和接收人；
- 能够撤销或替换失效/误发链接；
- 通知客户链接用途和到期时间；
- 不恢复已过期的小程序入口，除非负责人另行授权并记录；
- 不把网盘链接当成永久授权或公开分享链接。

网盘供应商、实际有效期和是否需要客户确认接收等仍需工作室确定。

### 9.3 原文件保管、备份与删除

已确认的产品规则是：小程序入口到期不删除工作室原文件。以下内容尚需单独制定工作室内部保管规则：

- 原片和精修文件的保管期限；
- 工作副本、备份副本和灾备副本的范围；
- 文件损坏或误删后的恢复流程；
- 订单、客户请求或授权撤回对原文件保管的影响；
- 依法或按客户请求需要删除时的审批和执行流程；
- 物理删除后备份副本何时清除；
- 访问和删除审计的保留期限。

在保管规则确认前，不能把入口到期任务扩展为自动清理原件、备份或审计记录。客户私密访问授权撤回也不自动等于文件必须立即物理删除。

## 10. 公开案例授权与撤回

### 10.1 默认不公开和明确同意

公开案例默认不公开。客户支付订单、参加拍摄、收取成片、未主动反对或工作室拥有文件，都不能替代明确的公开同意。

工作室需要在公开使用前取得可追溯的明确授权。授权内容至少需要让工作室识别：

- 同意的主体及其与影像中人物的关系；
- 授权覆盖的案例、图片或影像范围；
- 允许的用途，例如公开作品展示；
- 允许的渠道，例如小程序、官网或其他明确渠道；
- 授权有效期或撤回方式；
- 同意时间和可追溯证据；
- 是否存在需要额外确认的儿童、监护人或多人参与者。

授权证据具体保存方式、是否需要按单图确认、儿童监护人和多人意见冲突处理，需要工作室确认并由 A11/A06 协同校验。

### 10.2 授权范围

公开授权可以按不同粒度表达：

- 某一张图片；
- 一组图片或一个案例；
- 某些指定人物；
- 指定公开用途；
- 指定发布渠道；
- 指定有效期限。

授权不能默认从一张图片扩展到同一次拍摄的全部照片，也不能从一个渠道扩展到所有渠道。公开案例使用范围必须落在有效授权范围之内。

### 10.3 私密交付和公开授权相互独立

客户可以选择：

- 接受私密交付，但不允许公开；
- 允许某些图片或渠道公开，但仍只由授权客户访问原片/精修图；
- 撤回公开授权，但继续保留自己的私密交付访问；
- 撤回某个家庭成员的私密访问，但不自动撤回公开案例授权。

A15 必须为私密交付权限和公开案例授权分别维护业务结果，不以一个“客户授权”复选框同时控制两个场景。

### 10.4 公开授权撤回

客户或有权授权主体撤回公开授权后：

- 立即停止相关图片/案例进入新的公开展示；
- 通知 A06 重新计算案例资格；
- 通知 A05 移除首页引用或公开内容引用；
- 公开列表、详情、相关作品和可控分享入口按范围停止后续展示；
- 保留同意、撤回、处理时间和操作审计；
- 不向匿名访客展示客户姓名、撤回理由或内部处理记录；
- 不自动删除私密交付文件，也不自动取消客户自身的交付授权；
- 记录无法即时清除的缓存/搜索入口处理结果并提供人工跟进。

授权按单图撤回时，A06 可以在剩余图片仍符合案例内容和授权要求时保留案例；案例级、人物级或整体撤回时，A06 按整案隐藏规则处理。A15 负责授权范围判断与撤回事实，A06 负责公开展示资格消费。

### 10.5 授权变更和冲突

授权主体、家庭成员、监护关系或授权范围出现争议时：

- 暂停受影响内容的公开展示；
- 暂停新增公开发布或扩展用途；
- 保留现有授权证据和沟通历史；
- 转负责人/人工核验，不自行推断哪一方代表所有人；
- 争议解除后更新授权或维持隐藏结果。

无法确认授权有效性的图片默认不公开。

## 11. 公开案例使用和 A06 衔接

### 11.1 A15 的授权输出

A15 向 A06 提供业务层面的授权判断结果：

- 可公开/不可公开；
- 授权范围覆盖哪些图片、案例、人物、用途和渠道；
- 有效期和失效时间；
- 撤回或暂停状态；
- 后续展示是否需要限制或隐藏。

A15 不决定案例标题、分类、封面、相关作品顺序或首页推荐位置。

### 11.2 A06 的公开资格消费

A06 消费 A15 的授权结果后，结合案例状态、图片可用状态、内容校验和关联对象，决定：

- 是否能出现在公开作品列表；
- 是否能进入案例详情；
- 是否能被首页引用；
- 是否能出现在分类和相关作品；
- 单图撤回后剩余案例能否继续公开。

A06 不得将客户未拒绝、历史已经展示或私密交付已发布解释为公开授权。

### 11.3 多端公开一致性

小程序、官网、首页、作品列表、案例详情和分享入口不得因缓存或各自保存内容副本而在授权撤回后继续展示。授权状态发生变化后：

- 后续内容读取必须使用当前有效资格；
- 已缓存的公开媒体需要按公开访问策略失效或更新；
- 直接访问已撤回公开链接时返回统一不可用提示；
- 搜索或外部分享无法即时消除时记录处理结果并安排复核；
- 私密交付入口仍按自己的订单/身份/尾款/期限条件判断。

## 12. 通知、异常和人工补偿

### 12.1 客户通知

可能需要通知客户：

- 交付开始准备或工作室需要确认交付范围；
- 交付批次已发布；
- 交付入口截止时间；
- 入口即将到期；
- 文件校验或发布延迟；
- 私密交付授权新增、变更或撤回；
- 公开案例授权请求、记录结果或撤回执行结果；
- 网盘补充交付链接、范围和有效期；
- 访问拒绝、入口过期或文件暂不可用的下一步。

通知失败不能回滚文件校验、交付发布、授权或撤回事实。客户进入交付详情时仍要读取服务端真实状态。

### 12.2 文件和发布异常

以下情况需要在后台可见并提供处理入口：

- 上传失败或结果未知；
- 对象存在但业务登记失败；
- 业务记录存在但对象缺失；
- 文件类型/大小/哈希/数量校验失败；
- 文件绑定到错误订单或交付批次；
- 预览版本缺失或水印处理失败；
- 交付发布时尾款/授权状态发生变化；
- 发布任务重复或部分失败；
- 客户访问地址生成失败；
- 入口到期任务未执行；
- 撤回后仍有缓存或外部分享入口。

上传、对象存储和数据库不共享分布式事务。外部结果未知时需要保留处理状态并重试或转人工，不能将“上传请求已发出”显示为交付发布成功。

### 12.3 授权异常

授权缺失、主体不明确、范围冲突、过期、撤回、同意证据缺失或监护关系待确认时：

- 不公开受影响内容；
- 不扩大私密交付访问对象；
- 后台显示待核验原因和受影响范围；
- 负责人或授权人员核实后通过明确业务动作恢复；
- 客户侧不披露其他参与者和争议材料。

### 12.4 人工补偿

人工补偿至少支持：

- 重新检查对象和文件元数据；
- 重试上传、校验、水印处理和发布；
- 撤回错误发布或恢复错误下架；
- 重新计算入口有效期或进行负责人授权的例外处理；
- 撤销误发的家庭成员权限；
- 执行公开授权撤回后跨端下架复核；
- 重新生成网盘链接并撤销旧链接；
- 处理孤立对象和业务记录缺失；
- 记录无法清理的缓存或外部链接跟进结果。

每次补偿必须记录操作者、原因、时间、对象范围、前后状态和任务/请求关联。不得直接改一个 `published` 或 `authorized` 值来掩盖文件、授权或外部处理失败。

## 13. 功能需求清单

### 13.1 工作室交付管理

- 从订单进入交付准备；
- 创建或管理交付批次；
- 区分精修图片和原片；
- 上传、重传、校验和处理文件；
- 查看文件归属、数量、状态和异常；
- 预览客户侧交付效果；
- 校验尾款、身份授权和发布前置条件；
- 发布、撤回和查看入口截止时间；
- 对到期批次发起人工补交；
- 查看访问、下载和通知审计。

### 13.2 客户私密交付

- 预约联系人查看本人已发布交付；
- 显示精修图和原片分组；
- 满足条件后进行带水印预览；
- 正式下载不加水印且首版不限次数；
- 显示授权状态和入口截止时间；
- 无权限、未发布、尾款未付、入口到期和文件异常提供不同提示；
- 入口到期后引导联系工作室；
- 不允许未经后台显式授权的家庭成员访问。

### 13.3 私密交付授权

- 默认授权预约联系人；
- 后台添加其他已核验身份；
- 设置批次/文件范围、预览/下载权限和有效期；
- 授权变更和撤回可追溯；
- 不自动授予订单修改、支付或公开同意权限；
- 每次访问按当前有效授权重新判断。

### 13.4 公开案例授权

- 默认不公开；
- 记录授权人、对象范围、用途、渠道、有效期和证据；
- 支持案例级、图片级或明确确认的其他授权范围；
- 处理儿童、多人和监护关系核验；
- 提供授权结果给 A06 计算公开资格；
- 授权到期或撤回时触发公开展示停止和审计；
- 公开授权与私密交付授权分开管理。

### 13.5 到期、补交与文件保管

- 小程序入口开放期默认 1 周并支持后台配置；
- 每批次保存实际截止时间；
- 到期提醒和访问关闭；
- 负责人授权的网盘人工补充交付；
- 记录接收人、范围、链接有效期、操作者和原因；
- 原文件保管与客户入口到期分离；
- 物理删除采用单独且待确认的工作室运维规则。

## 14. 验收标准

### 14.1 上传、校验和发布

1. 工作室可以按订单建立交付任务并区分精修图片和原片。
2. 文件上传成功后仍处于未校验/待校验状态，不能直接对客户开放。
3. 错误订单、错误批次、文件不完整、类型不符或校验失败的文件不能发布。
4. 发布前检查订单、履约、尾款、授权、文件校验、访问范围和实际截止时间。
5. 发布失败时保持未发布或原有效版本，不出现部分文件意外公开。
6. 重复上传/校验/发布请求不会产生重复批次或重复授权事实。
7. 客户可以看到已发布的实际交付分组、有效状态和入口期限。
8. 文件缺失、访问地址生成失败或上传结果未知进入可观察重试/人工路径。

### 14.2 客户访问和下载

1. 尾款未结清前，客户无法预览或下载任何成片。
2. 尾款已付但交付未发布时，客户仍不能访问文件。
3. 客户访问还需要订单归属、私密授权有效和入口未到期。
4. 预约联系人默认可以访问本人订单的有效交付。
5. 其他家庭成员没有后台显式授权时不能访问。
6. 满足访问条件后，小程序预览为带水印版本，正式精修图和原片不加水印下载。
7. 正式下载首版不限次数，访问和下载有审计记录。
8. 无权访问时不泄露其他客户、订单存在性或对象存储路径。
9. 每次访问都按当前身份、尾款、发布、授权和期限重新判断，不能靠旧链接绕过撤回。

### 14.3 访问期限和补充交付

1. 小程序入口默认开放 1 周并可由后台配置。
2. 每个已发布批次保存实际截止时间，后续修改默认配置不回写历史批次。
3. 入口到期关闭小程序预览和下载，并向客户提供联系工作室路径。
4. 入口到期不删除工作室原文件或自动清理备份。
5. 网盘补充交付每次记录接收人、范围、有效期、操作者和原因。
6. 网盘链接不能被当作永久授权或小程序入口恢复。
7. 网盘链接失效或误发后有撤销/重新生成和审计路径。

### 14.4 私密授权

1. 预约联系人默认具有私密交付资格，但仍受订单、支付、发布和期限条件约束。
2. 实际拍摄人、付款人和家庭成员不会因关系自动获得交付访问。
3. 后台显式授权能够指定身份、范围、权限、有效期和授予/撤回人。
4. 被授权家庭成员不因此获得订单修改、退款审核或公开授权权限。
5. 撤回一个家庭成员授权后，其他授权对象是否仍有效按各自授权判断。
6. 私密授权撤回不会自动撤回公开案例授权，除非分别记录该项撤回。

### 14.5 公开授权和案例撤回

1. 公开案例默认不公开，必须有明确且有效的客户同意。
2. 支付成功、接收成片、未反对或工作室持有文件不能替代公开授权。
3. 授权事实可以说明授权主体、对象范围、用途、渠道、有效期和证据。
4. 授权单图或部分案例不能自动扩展到同一拍摄的其他图片。
5. 授权失效或撤回后，A06/A05 收到结果并停止公开展示、首页引用和相关作品推荐。
6. 案例级/人物级撤回按整案规则隐藏；单图撤回移除该图并重新计算案例资格。
7. 公开撤回不删除客户私密交付文件，也不自动取消私密访问授权。
8. 无法确认儿童、多人或监护授权范围时，相关内容默认不公开。
9. 授权撤回后保留审计且不向匿名访客暴露撤回原因或客户身份。

### 14.6 文件保管、权限和可靠性

1. 客户入口到期、公开授权撤回、私密访问撤回、网盘补交和物理删除分别记录。
2. 原文件物理删除不能由默认入口到期任务触发。
3. 负责人、管理员和摄影师按授权范围执行文件操作。
4. 摄影师上传候选文件不自动发布，也不能改变客户授权。
5. 对象存储不直接决定业务访问权；应用服务先检查授权再提供短期访问能力。
6. 上传、校验、发布、到期和撤回任务具备幂等、重试和失败待人工状态。
7. 高风险发布、授权变更、网盘补交和删除操作有操作者、时间、原因、对象和范围审计。
8. 错误响应不暴露对象路径、永久链接、SQL、堆栈、第三方原始响应或其他客户资料。

## 15. 验证方式

### 15.1 负责人和工作人员核验

需要工作室负责人确认：

- 精修图和原片的实际交付组织方式；
- 是否分批交付、是否需要选片或追加交付；
- 套餐中的数量、相册和交付承诺如何核实并进入订单快照；
- 交付前是否需要客户确认文件范围或选择照片；
- 首版是否支持水印预览与正式文件分开生成；
- 客户下载是否需要保留期限内不限次数；
- 入口开放 1 周是否适用于所有订单和业务；
- 到期提醒的时间和渠道；
- 家庭成员授权由谁申请、核验和批准；
- 儿童、婚纱双方、家庭多人影像授权主体如何确认；
- 公开案例授权是否按单图、案例、人物、渠道和有效期分别勾选；
- 公开授权证据的保存形式和负责人复核范围；
- 客户撤回公开授权后，官网、微信缓存和外部搜索的处理流程；
- 网盘补交使用的服务、链接期限和撤销能力；
- 原片、精修图、备份和工作文件的保管期限；
- 物理删除的申请、审批、执行和备份清除流程；
- 摄影师是否可上传客户私密文件以及可访问范围；
- 交付发布、授权变更和网盘补交的管理员/负责人权限差异；
- 交付失败、文件损坏和授权争议由谁跟进以及多久响应。

### 15.2 脱敏场景验证

至少准备以下场景：

1. 订单已付尾款但文件仍在上传，客户不能访问。
2. 文件已上传但校验失败，客户不能预览或下载，后台可以重传。
3. 文件已校验但交付未发布，客户仍不能访问。
4. 交付已发布但尾款支付结果未知，客户访问仍然关闭。
5. 尾款已付、交付已发布、预约联系人访问成功，预览带水印且正式下载不加水印。
6. 实际拍摄人不是预约联系人，未授权时不能访问订单交付。
7. 后台显式授权家庭成员后，该成员只获得设定范围内的交付访问权。
8. 家庭成员私密访问授权被撤回后，旧的客户入口不能继续访问。
9. 单张照片公开授权撤回，公开图片被移除并重新检查封面和案例资格。
10. 案例级/人物级授权撤回，公开列表、详情、首页和相关作品隐藏整案。
11. 客户允许私密交付但拒绝公开，交付正常而公开案例不可用。
12. 客户同意某些图片在官网公开，不允许其他图片或渠道，超范围内容不能发布。
13. 儿童或多人影像的授权主体/监护关系不明确，默认不公开并进入人工核验。
14. 小程序交付入口到期，客户不能访问，但工作室原文件仍保留。
15. 工作室通过网盘补交，记录接收人、文件范围、有效期和操作者。
16. 网盘链接误发或到期，工作室撤销旧链接并建立新记录。
17. 授权撤回后外部分享缓存仍存在，后台有跨端复核和跟进记录。
18. 对象存储已收到文件但本地登记失败，系统进入待补偿而不显示交付成功。
19. 本地显示文件已上传但对象不存在，系统停止访问并进入重传/人工处理。
20. 访问短期地址生成失败，客户获得安全重试提示，不泄露永久对象路径。
21. 重复发布、到期下架或撤回任务不会重复创建授权或删除原文件。
22. 摄影师上传候选文件，但不能直接发布或公开为作品案例。
23. 管理员尝试发布没有有效授权或尾款未付的交付批次，操作被阻止。
24. 人工补偿恢复错误下架批次时，先重新校验支付、授权、文件和期限。

### 15.3 客户和工作室可用性验证

观察客户是否可以：

- 理解尾款付清后仍需等待工作室发布；
- 区分预览、正式下载、公开案例和私密交付；
- 找到精修图和原片；
- 理解入口截止时间和到期后联系工作室的方式；
- 理解自己是否有访问权以及家庭成员为何需要显式授权；
- 提交授权撤回或访问问题，并理解后续处理。

观察工作室是否可以：

- 在上传和发布前检查文件属于正确订单和批次；
- 清楚识别尾款、校验和授权阻塞原因；
- 不把客户私密成片误放到公开案例；
- 处理单图撤回和整案撤回的差异；
- 在小程序入口到期后安全执行网盘补交；
- 区分关闭客户入口、撤回授权和删除原文件；
- 从审计记录还原谁访问、下载、授权、撤回和补交了什么。

在没有真实交付和授权数据前，不设定文件上传成功率、交付准时率、下载完成率、授权撤回处理时长和客户满意度目标；这些由 A16 结合运营基线确定。

## 16. 待确认经营内容与产品决策

以下事项需要负责人和实际工作人员确认：

1. 成片是一批交付还是允许分阶段发布多批次。
2. 首版是否包含客户选片、追加修图、电子相册或实体产品的后续流程。
3. 套餐中照片数量、相册和产品交付承诺以什么权威资料为准。
4. 精修图和原片的文件格式、数量范围和客户侧分组名称。
5. 是否在小程序生成单独的带水印预览版本，水印展示规则是什么。
6. 交付入口默认开放 1 周是否适用于所有订单，是否允许负责人延长或重新开放。
7. 入口到期提醒提前多久、通过什么渠道、失败后由谁跟进。
8. 家庭成员访问由预约联系人申请还是工作人员主动核验，谁有审批权。
9. 家庭成员可获得预览、下载还是仅部分文件访问，访问是否有时限。
10. 客户撤回家庭成员访问后，已下载文件如何告知和记录。
11. 公开授权的取得方式、证据格式和负责人员。
12. 授权范围是否按单张、案例、人物、渠道、用途和期限细分。
13. 儿童、多人合影、婚纱双方和监护关系的授权判断方式。
14. 多人对公开授权意见不一致时的默认处置和复核责任。
15. 单张图片撤回后是否保留案例，哪些敏感业务需要整案隐藏。
16. 官网、小程序、微信分享和其他外部渠道的授权是否分别确认。
17. 公开授权撤回后外部缓存、分享链接、搜索索引的跟进责任和期限。
18. 原片、精修图、工作文件和备份的保管期限与删除条件。
19. 客户隐私删除请求、法律要求和订单争议对文件保管的影响。
20. 物理删除是否需要负责人审批、双人复核和备份清除确认。
21. 网盘补交使用的服务、链接权限、有效期和撤销方式。
22. 网盘接收人是否需要重新核验身份，链接能否转发。
23. 交付校验失败、文件损坏或发布失败的响应时限和补偿方式。
24. 摄影师是否可以直接上传文件，能否查看预览，何时失去访问权。
25. 管理员的发布、撤回、授权变更和补充交付权限边界。
26. 下载审计需要记录哪些信息、保存多久、谁可以查看。

## 18. 结论

当前工程只有静态作品资源和“我的相册”占位，没有私密成片上传、文件校验、交付发布、客户授权或公开案例授权事实。A15 以已确认规则为准，建立完整目标：
